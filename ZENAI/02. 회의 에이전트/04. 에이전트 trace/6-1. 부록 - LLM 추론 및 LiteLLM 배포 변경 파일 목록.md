## 3. LiteLLM 이미지·실행·구성 — 7개

**아래 파일은 모두 `docker/litellm-sap/` 아래에 새로 추가**했다. Claude 호환 수정과 GPT 경로 변경이 같은 이미지에 포함되지만 역할은 다르다.

| 파일 | 역할 | 주요 관련 영역 |
| --- | --- | --- |
| `Dockerfile` | 고정한 공식 이미지 위에 패치와 빌드 시 테스트 적용 | **이미지 빌드** |
| `apply_patch.py` | 설치된 LiteLLM Python 코드에 옵션·응답 변환·인증 연결 패치 | **Claude + GPT** |
| `sap_reasoning.py` | SAP 추론 배열을 문자열로 정규화하고 원본 블록 보존·복원, 빈 logprobs 처리 | **SAP 응답 호환성** |
| `sap_responses.py` | 모델별 GPT 배포 주소 검증 및 SAP 인증 헤더 연결 | **GPT Responses** |
| `config.local.yaml` | 로컬 모델 목록과 Claude/GPT 호출 경로 정의 | **로컬 구성** |
| `start-local.mjs` | 환경변수를 읽어 로컬 검증용 LiteLLM 실행 | **로컬 실행** |
| `prepare-production.py` | 기존 운영 모델 설정을 보존하면서 GPT Responses 후보 설정 생성 | **운영 경로 전환** |

**이미지에 인증키나 배포 URL을 내장한 것이 아니다.** 실행 환경의 값을 참조하도록 연결했다. 수정 대상도 DB가 아니라 **LiteLLM 애플리케이션 이미지의 어댑터 코드**다.

## 5. 기존 GitHub workflow — 3개

**세 파일 모두 기존 파일 수정**이다. 이미지 파일을 하나 추가하는 수준을 넘어 기존 CI·배포·운영 흐름을 연결한 부분이다.

| 파일 | 추가·변경한 내용 |
| --- | --- |
| `.github/workflows/ci.yml` | **litellm-contract** 이미지 빌드·배포 계약 테스트를 추가하고 CI 성공 집계에 포함 |
| `.github/workflows/deploy.yml` | **조건부 LiteLLM 이미지 빌드·전송·전환**, 활성 구성 유지 및 복구 연결 |
| `.github/workflows/ops.yml` | **litellm-check / litellm-env-apply / litellm-env-rollback**, SSM 실행 및 보호 검사 연결 |

**deploy.yml은 앱 배포와 LiteLLM 전환을 연결**, **ops.yml은 조회뿐 아니라 URL 반영·복구도 수행**하도록 확장했다. 따라서 당시 구현은 “별도 수동 이미지 배포 workflow 하나”와는 다른 구조였다.

## 9. 변경하지 않은 부분과 정리 시 주의점

**#225~#231 범위에서는 DB 마이그레이션과 `docker-compose.ec2.yml` 자체를 변경하지 않았다.** 다만 추가한 운영 스크립트는 환경파일·후보 설정·컨테이너를 바꾸도록 설계했다. “Git의 Compose 파일이 그대로다”와 “운영 구성을 전혀 변경하지 않는다”는 같은 의미가 아니다.

**이 파일 목록은 삭제 목록이 아니다.** 이후 배포를 단순화할 때는 다음을 구분해야 한다.

| 구분 | 정리 시 고려할 사항 |
| --- | --- |
| **Trace 표시** | “LLM 추론:” 표시 등 원하는 앱 개선은 보존 |
| **Claude 호환 패치** | 이미지 단독 배포에도 필요한 변환 로직은 보존 |
| **GPT Responses** | 포기할 범위에 따라 앱·이미지·로컬 구성의 연결을 함께 검토 |
| **운영 배포 확장** | URL 적용·자동 전환·진단·복구 코드와 workflow 연결을 함께 정리 |
| **관련 테스트·문서** | 남긴 동작에 맞춰 수정하고, 오래된 안내가 남지 않도록 정리 |
| **#232 이후 별개 작업** | 백그라운드 실행·이미지 판독을 함께 되돌리지 않음 |

**#224로 저장소 전체를 되돌리는 것이 아니라, 필요한 파일과 변경 부분만 선별하는 작업**이어야 한다. 현재 문서는 이력을 정리한 부록이며, 코드 복원·삭제를 실행한 결과가 아니다.
