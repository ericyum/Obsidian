# ZEN AI 공지사항 UI 형식 비교와 권장 방향

현재 ZEN AI에는 **짧은 요약이 붙은 세로형 목록과 클릭해서 들어가는 상세 화면**을 권장한다. Vercel의 목록 구조, Slack·Asana의 업무 효과 중심 설명, Cursor의 시작 방법 안내를 조합한다.

직원은 목록에서 **무엇이 달라졌고, 내 업무에 왜 필요하며, 어떻게 시작하는지**를 파악하고, 필요한 경우에만 상세를 읽는다.

기준: [ZEN AI의 현재 상황](<../00. ZEN AI의 현재 상황과 공지사항 방향.md>) · [공지사항 UI 조사](<../../01. UI 조사/01. 공지 사항 UI 조사.md>). 아래 화면은 조사에 저장된 2026년 10월 14일 캡처다.

| --- | --- | --- | --- | --- |
| 제목·짧은 요약의 세로형 목록 | Vercel | 여러 변경의 의미를 빠르게 훑는다. | 기술 용어 중심 요약은 이해하기 어렵다. | **첫 화면의 기본형.** |

## 권장하는 ZEN AI 공지 목록과 상세 구성

### 1. 목록

| 특징 | 구성 | 방향과 의도 |
| --- | --- | --- |
| 가볍게 훑는 화면 | 최신순 한 열, 대형 이미지 없이 짧은 항목 | **여러 소식을 빠르게 비교한다.** |
| 업무 중심 제목 | 새 에이전트·개선 유형과 새로 할 수 있는 일 | 이름을 몰라도 자기 업무와의 관련성을 판단한다. |
| 짧은 요약 | 핵심 변화·업무 효과를 한두 문장으로 설명 | 상세를 열기 전에 변화의 의미를 이해한다. |
| 한 줄 시작 안내 | 에이전트 이름과 채널 초대·@요청의 시작 위치 | 초보자도 다음 행동을 찾는다. |
| 게시일·필수 조건 | 게시일, 권한 필요·제공 예정 등 필요한 조건 | 최신 여부와 실제 이용 가능 여부를 오해하지 않는다. |
| 상세 연결 | 제목 또는 ‘자세히 보기’ | **관심 있는 사람만 추가 설명을 읽는다.** |

제목·요약·사용 안내는 같은 말을 반복하지 않는다. 게시일과 적용일이 다르면 구분한다.

### 2. 상세

| 특징 | 구성 | 방향과 의도 |
| --- | --- | --- |
| 핵심 변화 재확인 | 목록의 제목과 요약 유지 | 관심을 가진 공지의 맥락을 이어간다. |
| 이용 조건 우선 | 적용 대상·시점·필요 권한 | **내가 사용할 수 있는지 먼저 확인한다.** |
| 실제 사용 순서 | 채널 초대 → @요청 → 스레드, 이미 초대된 경우의 안내 | ZEN AI의 실제 조작 흐름을 따른다. |
| 첫 요청과 결과 | 예시 질문, 준비 자료, 확인할 결과 | **무엇을 입력하고 무엇을 얻는지 알 수 있다.** |
| 필요한 보충 설명 | 스크린샷·세부 변경·주의사항·추가 가이드 | 필요한 사람만 더 깊게 읽는다. |
| 사용으로 연결 | 권한·초대 상태에 맞는 실제 채널·안내 경로 | 읽은 뒤 시작 위치를 찾도록 돕는다. |

## 쟁점: 첫 화면에서 필요한 정보를 충분히 얻는가

**사용자가 ‘이 에이전트는 무엇이고, 어떤 업무에 어떻게 활용하는지 알겠다’고 느끼는 정보량과 표현 방식은 사람마다 다를 수 있다.**

세 시안을 대상 사용자·동료들과 비교하며 의견을 들어야 한다. 설명·그림·질문·답변 예시 중 무엇이 필요한지, 상세를 열기 전에 부족하거나 과한 정보는 무엇인지 확인해 **첫 화면에 제공할 정보의 범위를 정한다.** 공통 조작법은 튜토리얼이 담당한다.

## 권한 구조와 다음 설계에서 정할 사항

### 1. 권한 구조에 맞게 고려해야 할 점

- **공지 열람 대상과 에이전트 사용 권한은 별도로 확인한다.** 다른 고객사 전용 정보의 노출을 막고, 사용 가능 여부가 확인되지 않으면 단정하지 않는다.
- 커뮤니티 공지와 플랫폼 공통 공지를 구분하고, 필요한 권한·문의 경로를 짧게 안내한다.

### 2. 다음 설계에서 정할 사항

- 공지의 게시·열람 범위, 기존 UI의 진입 위치, 새 공지·읽지 않음 표시 기준, 상세에서 실제 사용으로 이어지는 경로를 정한다.
- 실제 공지로 제목·요약 길이와 이미지·검색 필요성을 확인하고, **초보자가 변화·업무 관련성·시작 방법을 찾는지 검증한다.**
