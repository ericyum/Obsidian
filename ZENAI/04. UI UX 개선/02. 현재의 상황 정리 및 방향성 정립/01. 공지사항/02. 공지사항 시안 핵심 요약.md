# 공지사항 시안 핵심 요약

## 지금 해결하려는 문제

- ZEN AI의 핵심은 고객사·임직원이 채팅방에서 업무용 에이전트를 쓰는 것이다. 새 에이전트나 개선 기능을 만들어도 알리지 않으면 발견하기 어렵다.
- 사용자는 AI 원리보다 **“무슨 일이 가능해졌고, 내 업무에 왜 필요하며, 어떻게 쓰는가”**를 간단히 알고 싶어 한다.
- 따라서 첫 화면은 짧게 읽히고, 필요한 사람만 상세로 들어가야 한다. 커뮤니티와 사용 권한에 따른 이용 조건도 빠뜨리지 않는다.

세 시안은 **같은 ZEN AI 화면 틀과 같은 가상 공지 3건**을 사용한다. 차이는 첫 화면에서 무엇을 먼저 보여주느냐이다.

## 1. 요약 목록형 — 여러 소식을 빠르게 파악

[HTML 열기](<공지사항 HTML 시안/01-요약-목록형.html>) · Vercel 참고

날짜·변경 유형·업무 중심 제목·짧은 설명·한 줄 사용법을 세로로 나열한다. 사용자는 상세를 일일이 열지 않고도 **새 소식을 훑고 자신에게 필요한 공지를 고르기 쉽다.** 일상적인 공지 목록에 가장 잘 맞지만, 생소한 에이전트의 사용 장면을 보여주는 힘은 2번보다 약하다.

## 2. 업무 효과 카드형 — “나에게 왜 필요한가”를 먼저 전달

[HTML 열기](<공지사항 HTML 시안/02-업무-효과-카드형.html>) · Slack·Asana 참고

주요 공지 하나를 큰 카드로 강조하고 업무 효과와 채팅 사용 예시를 함께 보여준다. 사용자는 에이전트 이름을 몰라도 **자신의 업무에서 쓸 장면을 떠올리기 쉽다.** 중요한 신규 에이전트를 소개할 때 적합하지만, 카드가 넓어 여러 업데이트를 한꺼번에 비교하려면 더 스크롤해야 한다.

![업무 효과 카드형: 큰 소개 카드와 채팅 사용 예시](<공지사항 HTML 시안/screenshots/02-desktop.jpg>)

## 3. 시작 방법 강조형 — “어떻게 시작하는가”까지 연결

[HTML 열기](<공지사항 HTML 시안/03-시작-방법-강조형.html>) · Cursor 참고

주요 공지에 권한 조건, **초대 → @ 요청 → 스레드**의 세 단계와 복사 가능한 첫 질문을 바로 제공한다. 사용자는 어디서 무엇을 해야 하는지와 에이전트가 보이지 않을 때 확인할 조건을 함께 알 수 있다. 첫 사용을 유도할 때 적합하지만, 첫 화면의 설명량이 늘어나므로 모든 공지를 이 크기로 펼치기보다 주요 소개나 상세에 쓰는 편이 맞다.

![시작 방법 강조형: 권한 조건과 세 단계 사용 절차](<공지사항 HTML 시안/screenshots/03-desktop.jpg>)

## 현재 권장 조합

**기본 화면은 1번**, 제목과 요약은 **2번처럼 업무 효과 중심**, 상세 앞부분은 **3번처럼 이용 조건과 시작 방법 중심**으로 구성한다. 특히 알리고 싶은 새 에이전트가 있을 때만 2번의 강조 카드를 작게 추가한다. 사용자가 먼저 필요한 소식을 고르고, 관심이 생겼을 때 실제 사용 방법까지 이어서 확인할 수 있는 조합이다.

> 위 장점은 화면 구조로부터 기대하는 효과이며 사용자 실험으로 측정된 결과는 아니다. 이미지는 기존 시안의 저장된 캡처다. 세 HTML은 공지 열기·복귀·예시 복사를 비교하는 체험용이며, 실제 게시·권한 확인·읽음 저장은 연결되지 않았다.
