# ZEN AI 공지사항 HTML 시안

같은 ZEN AI 화면 틀에 공지사항 본문만 다르게 구성한 세 가지 시안입니다. HTML 파일을 브라우저에서 열면 됩니다. 글꼴·스타일·아이콘·스크립트가 각각의 HTML에 포함되어 인터넷 연결 없이도 볼 수 있습니다.

| 파일 | 비교할 점 |
| --- | --- |
| [01. 요약 목록형](01-요약-목록형.html) | Vercel 참고. 날짜, 짧은 요약, 사용 방법을 세로 목록으로 배치합니다. |
| [02. 업무 효과 카드형](02-업무-효과-카드형.html) | Slack·Asana 참고. 사용자가 얻는 업무 결과와 사용 장면을 강조합니다. |
| [03. 시작 방법 강조형](03-시작-방법-강조형.html) | Cursor 참고. 사용 조건, 초대→멘션→스레드의 시작 절차를 먼저 보여줍니다. |

2026-10-15 현재 열린 ZEN AI 화면과 workspace-shell·sidebar·channel-header·profile-popover·globals.css를 대조했습니다. 밝은 기본 테마의 실제 색상, 300px 사이드바, 40px 상단 바, 52px 본문 헤더, 본문 좌상단 둥근 모서리와 Pretendard 글꼴을 사용했습니다. 실제 앱의 기존 ‘공지사항’ 채팅 채널은 유지하고, 별도의 공지사항 메뉴를 제안 위치에 추가했습니다.

## 체험 가능한 부분

- 공지 제목 또는 자세히 보기로 상세 열기.
- 전체 공지사항·상단 뒤로 가기·Escape로 목록 복귀.
- 사이드바 접기. 작은 화면에서는 사이드바 열기와 바깥 영역으로 닫기.
- 예시 요청 복사. 브라우저의 로컬 파일 클립보드 제한이 있으면 안내 문구 표시.

## 검토 범위와 한계

- 세 파일은 동일한 가상 공지 3건을 사용합니다. 에이전트명·기능·게시일은 실제 제공 사실을 의미하지 않습니다. 실제 대화 내용은 포함하지 않았습니다.
- 제품의 기존 메뉴·검색·알림·프로필은 모양을 재현한 부분으로, 실제 기능에 연결하지 않았습니다. 사이드바 폭 조절과 테마 전환은 포함하지 않았습니다.
- 공지 3 표시는 예시 항목 개수입니다. 개인별 읽음 저장, 권한 확인, 커뮤니티 분리, 게시 기능은 구현 범위가 아닙니다.
- 프로덕션 소스와 백엔드는 수정하지 않았습니다. 실제 적용 시 승인된 intent 및 하네스 절차를 별도로 거쳐야 합니다.
- Pretendard 글꼴 라이선스는 함께 있는 Pretendard-LICENSE.txt를 확인하세요. Lucide 아이콘은 기존 프로젝트 의존성을 사용했습니다.
