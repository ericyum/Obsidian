# 공지사항 HTML 시안 검증

2026-10-15에 세 가지 HTML 파일을 검증했습니다. 프로덕션 앱은 수정하지 않았습니다.

## 확인한 내용

- 실제 ZEN AI와 동일한 기본 밝은 테마의 색상, 300px 사이드바, 40px 상단 바, 52px 본문 헤더, Pretendard 글꼴을 적용했습니다. 실제 대화 내용은 사용하지 않았습니다.
- Chrome의 1280×609 화면과 390×844 화면에서 세 파일을 각각 열어 가로 넘침이 없음을 확인했습니다.
- 세 시안 모두 실제 브라우저에서 공지 상세를 열고 목록으로 돌아갔습니다.
- 작은 화면에서 사이드바 열기와 바깥 영역 클릭으로 닫기를 확인했습니다. 닫힌 사이드바에는 키보드 포커스가 들어가지 않도록 처리했습니다.
- 별도 DOM 검사에서 각 파일의 공지 3건 상세, 제목 포커스 이동과 복귀, Escape, 데스크톱·모바일 사이드바, 복사 성공·제한 상황 안내를 확인했습니다. 세 파일 모두 통과했습니다.
- 글꼴·아이콘·스타일·스크립트는 HTML에 포함했습니다. 외부 리소스에 대한 참조가 없는지 검사했습니다. 실제 인터넷 연결을 끊는 검사는 하지 않았습니다.

공지 목록의 3은 예시 공지 개수입니다. 실제 읽음 이력이나 개인별 사용 권한을 조회하지 않습니다. 브라우저의 로컬 파일 정책에 따라 예시 복사가 제한될 수 있으며, 그때는 직접 선택하도록 안내합니다. 실제 제품의 데이터·권한·게시·알림 기능과 통합하지 않은 화면 시안입니다.
