# 튜토리얼 시안 핵심 요약

ZEN AI 이용자가 익힐 핵심은 **에이전트 초대 → @로 요청 → 스레드에서 결과 확인**이다. 기본 화면을 소개하는 키안닷컴식 안내와 실제 조작을 돕는 Driver식 안내는 함께 제공할 수 있다. 따라서 시안을 **옆 패널형과 상단 바형 두 개**로 정리했다.

## 두 시안에서 비교할 것

| 시안 | 차이 | 사용자 입장에서의 장점 |
| --- | --- | --- |
| [1. 사이드바형](<튜토리얼 HTML 시안/01-체크리스트와-실습.html>) | 채널 옆 패널에 다음 행동·전체 순서·진행 상태 | 현재 할 일과 남은 과정을 한눈에 파악한다. 처음 쓰는 직원에게 기본안으로 권장한다. |
| [2. 상단 바형](<튜토리얼 HTML 시안/02-화면-위치-안내.html>) | 채널 위 바에 현재 단계·설명·행동 | 채널 너비를 넓게 사용하면서 짧은 안내를 따른다. 대신 세로 공간을 사용한다. |

## 두 파일에 모두 포함한 흐름

1. **기본 화면 소개:** 키안닷컴식 환영 카드와 진행 점으로 채널·에이전트·입력창을 소개한다. 건너뛸 수 있다.
2. **에이전트 실습:** Driver식 대상 강조와 숫자 단계로 초대·요청·결과 확인을 돕는다. 실제 행동을 해야 진행한다. 강조 안내를 닫아도 옆 패널·상단 바를 보며 계속할 수 있다.
3. **다른 에이전트로 응용:** 두 번째 과제는 설명을 줄이고, 필요하면 상세 힌트를 연다. 현재 조작 대상의 초록색 테두리는 두 시안의 1·2회차 모두 유지한다.
4. **중단·완료 후 재진입:** 완료 전에는 왼쪽 온보딩 메뉴, 완료 후에는 프로필 → 설정 → 온보딩에서 다시 찾는다.

![공통 첫 화면 소개](<튜토리얼 HTML 시안/screenshots/01-integrated-intro-desktop.jpg>)

![공통 Driver식 실습 안내](<튜토리얼 HTML 시안/screenshots/02-integrated-driver-desktop.jpg>)

기존 3번의 공통 흐름과 4·5번의 소개·실습 안내를 1·2번에 통합했다. 별도 3·4·5번 HTML은 정리했다. **이제 선택 기준은 안내 위치**이며, 첫 소개와 실습 안내의 유무는 두 파일에서 같다.

소개 종료, 수동 체크, 예시 결과 확인, 온보딩 완료는 서로 구분한다. 시안은 가상 에이전트와 고정 결과를 사용하며 실제 업무 성공을 검증하지 않는다. 장점은 사용자 관찰 전 설계 가설이다.
