# ZEN AI 통합 튜토리얼 시안

독립 HTML 두 개를 브라우저에서 연다. 글꼴·아이콘·스타일·스크립트가 파일 안에 포함되어 있다.

| --- | --- |
| [01 체크리스트와 실습](01-체크리스트와-실습.html) | 채널 옆 패널에 전체 순서·현재 행동·진행 표시 |
| [02 화면 위치 안내](02-화면-위치-안내.html) | 채널 위 바에 현재 단계·설명·행동 표시 |

두 파일 모두 **키안닷컴식 기본 화면 소개 + Driver식 실습 안내 + 온보딩 재개·완료 후 설정 진입**을 제공한다. 기존 3·4·5번은 두 파일에 통합했다.

## 확인 순서

1. 첫 실행의 화면 소개를 보거나 건너뛴다. 소개 종료 후 체크리스트가 열린다. 건너뛰었으면 왼쪽 온보딩 메뉴에서 다시 연다.
2. 첫 항목의 ‘실습하기’를 누른다. 밝게 강조된 멤버 버튼에서 회의 도우미를 선택해 초대한다.
3. 예시 요청을 넣고 직접 전송한 뒤 스레드를 열어 결과를 읽는다. ‘내용을 확인했어요’를 눌러야 해당 실습이 확인된다.
4. 강조 안내의 닫기 버튼은 상세 안내창과 어두운 배경을 닫는다. 현재 대상의 초록색 테두리와 옆 패널·상단 바는 유지되어 실습을 계속할 수 있다. 중단하려면 ‘나중에 하기’를 누른다.
5. 다른 에이전트로 두 번째 과제를 해본다. 두 시안 모두 힌트를 열지 않아도 멤버 버튼 → 입력창 → 스레드 → 결과 확인 버튼에 초록색 강조가 이어진다. 설명은 짧게 유지하며 ‘막히면 힌트 보기’로 상세 안내창을 연다.
6. 체크리스트의 두 항목 확인 후 ‘온보딩 완료’를 누르면 왼쪽 온보딩 메뉴가 숨겨진다. 프로필 → 설정 → 온보딩에서 소개·실습을 다시 연다.

체크리스트의 ‘기본 화면 둘러보기’는 소개, ‘강조 안내로 실습하기’는 미완료 과제를 이어가는 실습 진입점이다. 두 실습을 마친 뒤 다시 실습하면 새 시도를 시작하고 이전 온보딩 완료 상태는 유지한다.

## 범위

- 가상 에이전트·합성 메모·고정 결과의 체험이며 실제 메시지나 AI 요청을 전송하지 않는다. Driver.js 패키지를 도입하지 않았다.
- 첫 소개·수동 체크·예시 결과 확인·온보딩 완료는 서로 다른 상태다.
- 진행은 같은 브라우저의 로컬 저장소에만 남는다. 파일 위치·브라우저가 달라지면 이어지지 않을 수 있고, 직접 입력한 문장은 저장하지 않는다. 통합본 첫 실행은 새 안내로 시작한다.
- 작은 화면에서는 1번 옆 패널을 채널 위로 옮긴다. Driver 안내 중에는 중복 설명을 접어 입력·결과 확인 공간을 확보한다.
