# 통합 튜토리얼 시안 검증 결과

2026-10-15 · 기존 다섯 시안을 두 HTML로 통합한 후 확인했다.

## 확인 결과

- **두 파일의 동작 검증 통과:** 소개의 이전·다음·건너뛰기·재개, 실제 초대·멘션 전송·스레드 열기·결과 확인, 두 번째 과제, 명시적 온보딩 완료, 설정 재진입, 모바일 키보드 이동, 외부 에셋 없이 열리는 구성을 DOM 기반 자체 검증으로 확인했다.
- **차이 유지:** 1번은 옆 패널, 2번은 상단 바를 표시한다. 두 파일 모두 기본 화면 소개와 Driver식 실습 안내를 제공한다.
- **초록색 대상 강조:** 두 시안의 1·2회차 모두 멤버 버튼 → 입력창 → 스레드 → 결과 확인 버튼의 초록색 강조를 DOM 자체 검증으로 확인했다. 2회차는 힌트를 열지 않은 상태에서도 표시된다. Driver 안내창의 대상 테두리도 초록색이다.
- **강조 닫기:** 상세 안내창을 닫아도 실습은 열려 있고 현재 대상의 초록색 테두리와 일반 안내가 남는다. 첫 소개를 닫았거나 실습을 중단했을 때는 완료 전 온보딩 메뉴에서 재개한다.
- **상태 구분:** 소개 종료·수동 체크·예시 결과 확인·온보딩 완료를 구분한다. 완료 후 다시 실습해도 기존 온보딩 완료 상태를 유지한다.
- **Chrome 화면 확인:** 기본 1280×665와 작은 화면 390×844에서 확인했다. 1번은 작은 화면에서 옆 패널이 위쪽으로 이동하며 가로 넘침이 없었다. 2번은 작은 화면에서 초대부터 결과 확인까지 직접 진행했고 말풍선이 입력창·확인 버튼을 가리지 않았다. 확인 중 콘솔 error/warn은 없었다.
