# 대시보드 시안 핵심 요약

[대시보드 HTML 열기](<대시보드 HTML 시안/01-전체-에이전트-비교형.html>)

ZEN AI의 에이전트를 운영·개선하는 개발자를 위한 화면이다. **하나의 HTML에서 ‘전체 비교 / 문제 추적 / 개선 검토’ 탭을 전환한다.** 기본 탭은 전체 비교이며, 시작 탭만 달랐던 별도 2·3번 HTML은 정리했다.

## 각 탭에서 무엇을 보고 판단하는가

| 탭 | 주요 요소 | 개발자가 얻을 인사이트·방향 |
| --- | --- | --- |
| 전체 비교 | 실행 수·호출자·실패율·소요 시간 p95, 에이전트 비교표, 일별 추세, 기록 수집 범위 | **사용량과 실패·지연을 함께 보고 먼저 점검할 에이전트를 고른다.** 사용 0이면 권한·공지 도달·업무 수요부터 확인한다. |
| 문제 추적 | 실패·60초 이상·수집 누락 분류, 실행 목록, 요청·답변·평가, 모델·도구 호출 흐름 | **오류가 반복되는 입력·도구 단계를 찾아 점검 범위를 좁힌다.** 기록이 부족하면 원인 판단에 앞서 수집을 보완한다. |
| 개선 검토 | 관측 근거·가설·다음 확인 카드, 근거 실행 연결, 버전별 실패율·p95·표본 비교 | **장애 수정·답변 구성 개선·첫 사용 장벽 점검 중 다음 작업을 정한다.** 버전별 차이는 개선 효과의 확정이 아니라 추가 검증 근거로 쓴다. |

## 쟁점: 각 항목이 인사이트와 개선 방향 결정에 필요한가

**전체 비교·문제 추적·개선 검토 탭의 각 항목이 실제로 인사이트를 얻고 다음 개선 방향을 정하는 데 필요한지는 아직 확인하지 않았다.**

실제 모니터링·개선 작업을 하는 개발자와 운영 담당자의 의견을 들어야 한다. 판단에 도움이 된 항목, 부족한 정보, 빼도 되는 항목을 확인해 **유지·보완·제외할 요소를 정한다.**

## 권장 흐름

**전체 비교에서 대상 선택 → 문제 추적에서 개별 근거 확인 → 개선 검토에서 다음 작업 결정.** 커뮤니티·기간·에이전트 필터는 탭 이동 시 유지된다.

예: SAP 도우미의 실패 증가 → 실패 실행의 도구 응답 확인 → 반복되는 입력 조건을 비교해 도구 연동 수정·재현 검증을 할지 결정한다.

화면: [전체 비교](<대시보드 HTML 시안/screenshots/01-overview-desktop.jpg>) · [문제 추적 · SAP 필터](<대시보드 HTML 시안/screenshots/02-diagnosis-desktop.jpg>) · [개선 검토](<대시보드 HTML 시안/screenshots/03-improvement-desktop.jpg>)

모든 수치는 합성 예시다. 실행 완료는 업무 성공, 토큰은 비용, 평가 없음은 불만족을 뜻하지 않는다. 실제 API와 집계는 연결하지 않았으며, 개선 효과는 검증하지 않았다.
