# ZEN AI 개발자 대시보드 HTML 시안

ZEN AI의 화면 틀을 유지한 독립 HTML 한 개다. 글꼴·아이콘·스타일·스크립트가 파일 안에 포함되어 있다.

[대시보드 HTML 열기](01-전체-에이전트-비교형.html)

**전체 비교 / 문제 추적 / 개선 검토** 탭으로 모든 관점을 조작한다. 전체 비교가 기본 시작 탭이며, 시작 탭만 달랐던 기존 2·3번 HTML은 정리했다.

## 확인 순서

1. **01을 연다.** 상단 커뮤니티·조회 기간·에이전트 필터를 바꾸고, 표·요약 지표·추세가 같은 조건을 사용하는지 살펴본다. 커뮤니티 선택은 독립된 가상 데이터셋 전환이다.
2. **비교표를 읽는다.** 실행 많은 순·실패율 높은 순·p95 긴 순으로 정렬한다. 실패율의 분자·분모, 소요 시간의 표본 수, 호출 흐름 수집 범위를 함께 본다.
3. **문제 실행으로 들어간다.** 상단 「실행 살펴보기」 또는 표의 실패율을 누르면 해당 에이전트로 필터가 좁혀지고 「문제 추적」이 열린다. 에이전트 이름을 누르면 해당 에이전트의 「개선 검토」가 열린다.
4. **실행 상세를 읽는다.** 「실패 / 60초 이상 / 수집 확인 / 전체 실행」에서 분류를 고른 뒤 실행 행을 누른다. 오른쪽(좁은 화면에서는 목록 아래)에서 요청·답변·평가·호출 흐름을 확인한다. 목록이 12개를 넘으면 「조건에 맞는 전체 실행」으로 전체 후보를 열 수 있다.
5. **개선 근거를 확인한다.** 「개선 검토」에서 「근거 실행 보기」를 누르고 실행 ID를 선택한다. 관측된 문제와 가설이 일치하는지 비교한다. 관측 실행이 없는 에이전트의 「확인 항목 보기」는 권한·공지·업무 빈도 등의 점검 순서를 보여준다.
6. **전체를 다시 본다.** 특정 에이전트로 좁힌 상태는 탭 이동 시 유지된다. 다시 비교하려면 에이전트 필터를 「전체 에이전트」로 바꾼다. 실행 상세 창은 닫기 또는 Escape로 닫는다.

## 범위와 한계

- 실제 API와 연결하지 않은 화면 검토용 시안이다. 에이전트·질문·답변·호출 흐름·수치는 모두 합성 샘플이며 실제 운영 현황이나 실제 사용자 정보가 아니다.
- 초기 비교 범위는 사용자 에이전트(custom)다. 커뮤니티 간 합산이나 개발자에게 원문 조회 권한을 새로 부여하는 기능은 포함하지 않는다.
- 집계 단위는 Run이며 사용자 요청 수·업무 해결 건수와 다르다. `done`은 기술적 완료이고 업무 품질 보증이 아니다. 토큰은 금액 비용이 아니며 미수집은 0과 구분한다.
- 개선 카드는 규칙으로 만든 검토 후보다. 원인 확정·자동 수정·자동 배포 기능은 없다. 60초는 시안의 탐색 기준이며 운영 SLA가 아니다.
- 대시보드 필터·탭·정렬·상세·사이드바는 조작할 수 있다. 검색·알림·나머지 업무 메뉴는 화면 재현용이다. 조회 상태는 브라우저를 새로 열면 초기화된다.
- Pretendard·Lucide 라이선스를 함께 포함한다.
