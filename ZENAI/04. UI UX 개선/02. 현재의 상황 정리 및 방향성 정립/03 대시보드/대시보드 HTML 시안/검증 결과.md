# 대시보드 시안 검증 결과

2026-10-15 · 최초 독립 HTML 3개를 검증한 뒤, 시작 탭만 다른 중복 파일을 정리해 1번 HTML 하나로 유지한다. 아래 최초 검증 기록과 단일 파일 재확인을 구분한다. 실제 서비스 배포 검증은 아니다.

## 확인한 내용

| 구분 | 확인 결과 |
| --- | --- |
| 화면 | Chrome에서 1440×960 데스크톱과 390×844 모바일 화면을 확인했다. 모바일 페이지·상세 창의 가로 넘침이 없고, 필터와 상세 내용에 접근할 수 있었다. |
| 공통 조건 | 커뮤니티·기간·에이전트 필터를 바꾸면 카드·표·추세·개선 근거에 같은 조건이 반영됐다. 비교에서 문제 추적으로 이동해도 조건이 유지됐다. |
| 개별 근거 | 전체 실행 목록, 선택한 실행의 요청·답변·피드백·호출 흐름, 부정 평가의 근거 실행을 열었다. Escape로 상세 창을 닫으면 열기 버튼으로 포커스가 돌아왔다. |
| 계산 | 3개 HTML 모두 DOM 기반 자체 검증 통과. 실패율 분모, p95 표본 계산, 토큰 기록 범위, 관측 없음, 비활성 구분, 조건 필터를 확인했다. |
| 수정 후 확인 | 같은 날의 실행을 시각 내림차순으로 정렬하고, 분류 버튼 선택 후 키보드 포커스를 유지하도록 수정했다. 부정 평가 상세에 합성 요청·답변을 추가했다. |
| 오류·파일 | 확인 시 브라우저 콘솔 error/warn 0건. HTML의 글꼴·아이콘·스타일·스크립트는 파일 안에 포함되어 외부 에셋 요청이 없다. |

기본 조건(ZEN AI · 사내, 10월 8–14일)의 표본 검산: 관측 실행 136회, 고유 호출자 16명, 실패율 22/131 = 16.8%, 소요 시간 p95 68초. 모두 합성 데이터다.

## 단일 HTML로 정리한 후 재확인

- 남긴 1번 HTML의 내용은 변경하지 않았다. 전체 비교·문제 추적·개선 검토의 탭 전환, 공통 필터 유지, 실행·개선 근거 열기를 DOM 기반 자체 검증으로 다시 확인했다.
- 핵심 요약·상세 방향·지표 정의·README를 한 HTML·세 탭 기준으로 맞췄다. 정리한 파일을 가리키는 링크가 남지 않도록 확인했다.
