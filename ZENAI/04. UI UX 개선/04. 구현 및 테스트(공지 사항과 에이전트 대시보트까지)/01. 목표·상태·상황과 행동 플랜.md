## 3. 상황과 경계
- **현재 브랜치 유지. 커밋·push·main 병합·운영 배포는 하지 않는다.** 앞서 허용한 UI/UX 직접 수정 예외를 적용하고 수용 기준과 검증을 기록한다.
- 기존 채팅·회의·LiteLLM·하네스 실행 로직·프로젝트 공통 설정은 필요한 연결 외에는 보존한다.
- DB 연결 호스트가 localhost/127.0.0.1임을 확인한 뒤 로컬만 사용한다. Docker 컨테이너는 추가로 만들지 않는다.
- 사용자 계정·업무 데이터를 임의 수정하지 않는다. E2E는 **구분 가능한 합성 사용자/커뮤니티/실행 자료**를 사용하고 생성 범위를 기록한다.
- 대시보드는 **해당 커뮤니티의 활성 owner/admin 멤버만** 조회한다. 플랫폼 관리자·지원 열람을 이유로 원문 접근을 넓히지 않는다.
- 실행 완료는 업무 성공, 토큰은 청구액, 평가 없음은 불만족을 의미하지 않는다.
