## 앞선 런타임 수정에서 보존할 계약

PR #288·#289는 후속 설계의 기준에서 이미 병합된 선행 수정이다. 조각 간 도구 대화와 확인 결과 보존, 마무리 예산, 로컬 도구 집계, 하네스 종료 정보 보존을 다시 구현하거나 되돌리지 않는다. 일반·생성 하네스는 이미 같은 worker와 worker-runtime을 공유한다.

상위 #293은 Builtin에서 진행 문구+도구 호출 뒤 마지막 모델 단계가 빈 stop이어도 누적 문구를 답으로 인정하던 문제와, 빈 답변에 부분 원문 안내를 붙여 성공으로 보던 문제를 보완했다. 실제 마지막 답변을 검증하되 신뢰된 도구 완료·사용자 대기·background 접수 등 기존 종료 계약은 유지한다. 유효한 답이 확인된 뒤 앞 단계의 독립 답변을 일괄 지우지 않는다.

명확한 HTTP403·검증된 transport status·구조화된 권한 오류만 확정 거절로 처리한다. 일반 데이터의 403/Forbidden 문자열이나 isError만으로 차단하지 않는다. 확정 거절 뒤에는 현재 요청의 추가 모델·도구·continuation·closing·자동 재접수·성공 게시를 막고 최초 원인과 실패 안내를 보존한다. custom authorization_denied는 기존 access_denied 필터에 연결한다.

설계 원본은 저장소의 docs/superpowers/specs/2026-10-27-agent-harness-fix-design.md와 intents/agent-harness-fix.md다. 원본 설계의 “구현 중/다음 migration0118”은 당시 계획이며 현재 통합 결과·0121~0124 번호와 혼동하지 않는다.
