# 회의록 UI/UX 구상안 (v2 — 전사 기반)

🎨 **상세 화면 목업(SVG, zen-ai 테마 적용)**: https://claude.ai/code/artifact/0a564171-0f52-44eb-94c9-d9b3eb11ee1e

## 1. 문제 정의

실제 회의(음성)를 **녹음/업로드 → 전사(STT) → AI 구조화**를 거쳐 노션 회의록 같은 영속 문서로 만드는 기능. 채팅 대화 요약이 아니라, 회의 오디오가 원본이다.

## 2. 핵심 원칙

1. **오디오·전사가 원본, 회의록은 파생물** — 회의록 문서에서 전사 원문으로 언제든 내려갈 수 있어야 한다(문단 단위 근거 추적).
    
2. **AI 초안 → 사람 확정** — 전사·구조화까지는 자동, 문서 확정은 사람. 확정 전에는 항상 "초안" 배지.
    
3. **긴 처리는 화면을 붙잡지 않는다** — 전사·요약은 수 분 걸릴 수 있으므로 백그라운드 처리 + 목록에서 진행 상태 표시. 완료되면 인박스 알림.
    
4. **기존 화면 문법 재사용** — 사이드바 메뉴 + 목록/상세 2단(Inbox와 동일), 문서 상세는 문서 뷰 + 우측 전사 패널. 새 화면 문법 도입 없음.
    

## 3. 화면 구성

### 3-1. 진입점

|   |   |   |
|---|---|---|
|진입점|위치|동작|
|사이드바 "회의록" 메뉴|Inbox·나중에 볼 항목 아래 (lucide FileText)|/minutes 목록으로 이동|
|목록 화면 우상단 "+ 새 회의록"|/minutes|생성 플로우 시작|
|채널 헤더 ⋯ 메뉴 "회의록 만들기" (후순위)|채널 상단|관련 채널이 미리 지정된 생성 플로우|

### 3-2. 목록 화면 /minutes

Inbox와 동일한 **좌측 목록 + 우측 미리보기** 2단 레이아웃.

- 목록 아이템: 제목 · 회의 일시 · 길이(예: 42분) · 상태 배지(전사 중/초안/확정) · 액션 아이템 수
    
- 처리 중 아이템은 진행 표시(전사 중 → 초안 생성 중)와 함께 목록 상단 고정
    
- 필터: 전체 / 내가 참석 / 관련 채널별
    
- 빈 상태: "아직 회의록이 없습니다. 첫 회의를 녹음하거나 파일을 올려보세요." + [+ 새 회의록]
    

### 3-3. 생성 플로우 (모달 1개)

입력 방식 2택:

1. **녹음** — 브라우저 마이크로 즉시 녹음 시작. 녹음 중에는 경과 시간 + 일시정지/종료. 종료하면 자동으로 전사 시작.
    
2. **파일 업로드** — 오디오 파일(m4a/mp3/wav 등) 드래그&드롭. 업로드 진행률 표시.
    

공통 메타 입력(선택): 제목(비우면 AI가 제안), 회의 일시(기본: 지금), 관련 채널.

제출 후에는 모달을 닫고 목록으로 — 처리 상태는 목록 아이템 + 완료 시 인박스 알림으로 전달.

### 3-4. 상세 화면 (문서 뷰)

👉 **목업 보기(zen-ai 토큰 적용, 다크모드 대응)**: https://claude.ai/code/artifact/0a564171-0f52-44eb-94c9-d9b3eb11ee1e

위 목업은 **전사가 끝나고 AI 초안이 만들어진 직후, 사람이 검토하는 상태**를 그린 것이다.

구성 요약:

- **좌측 = 회의록 본문** — 고정 템플릿(요약 / 안건별 논의 내용 / 결정 사항 / 액션 아이템). 섹션 단위 인라인 편집. 별도 블록 에디터 도입하지 않음.
    
- **우측 = 전사 원문 패널** — 스레드 패널과 같은 접이식 우측 패널. 화자 라벨 + 타임스탬프 단위 세그먼트, 전사 내용 검색, 화자별 보기.
    
- **헤더** — [초안] 배지 + 제목 + 메타(일시 · 길이 · 참석자 아바타 · 관련 채널 칩).
    
- **근거 추적** — 회의록 문단에 마우스를 올리면 오른쪽 전사의 해당 구간이 하이라이트된다(목업은 "결정 사항 2 ↔ 07:41" 연결 상태). **v1 후순위** — 초반에는 단순 병렬 표시만.
    
- **화자 매핑** — 전사 엔진이 나눈 화자(Speaker 1, 2…)에 워크스페이스 멤버를 붙인다. 매핑이 끝나야 참석자 목록과 액션 아이템 담당자 추천이 정확해진다.
    
- **액션 아이템** — 체크박스 + 담당자 + 마감일. 확정 후에도 체크 상태만 갱신 가능.
    
- **공유 카드 미리보기** — 확정 시 채널에 게시될 카드를 문서 안에서 미리 보여준다.
    

### 3-5. 확정 시 동작

- 초안 → 확정 (확정자·확정 시각 기록). 확정본은 재전사로 덮어쓰지 않음 — 재생성은 새 버전 초안.
    
- 관련 채널 지정 시 채널 타임라인에 **회의록 카드** 게시(제목 + 요약 2줄 + 액션 아이템 수 + 링크) → 채널 멤버 인박스에 노출.

## 5. 스타일 가이드 (기존 컨벤션 준수)

새로 색이나 크기를 정하지 않고, src/app/globals.css에 이미 있는 디자인 토큰과 규칙을 그대로 쓴다.

- 색은 CSS 변수로만 지정 — 카드 배경 --content-elevated, 초안 배지 --amber, 확정 배지 --jade, 실패 --danger, 근거 하이라이트 --search-highlight. 하드코딩 금지(라이트/다크 자동 대응을 위해).
    
- 글자 크기는 기존 스케일 준수 — 본문 15px / 보조 14px / 메타 12px.
    
- AI 고지 문구·카드 스타일은 스레드 요약 카드(thread-panel.tsx) 선례를 계승, 전사 패널은 스레드 패널 레이아웃을 계승.
    
- 모든 문자열 한국어, lucide 아이콘 15~17px.
