# 문서 4 전용 시각 자료

- 01: 현재 호출·등록·승인 경계
- 02: 후보 B + 이행 전략 D의 소유권 (제안)
- 03: 모델 등록·퇴역 절차 (제안)
- 04: R0–R3 기록 범위 (제안, 실측 그래프 아님)

PNG는 본문 표시, SVG는 확대, .excalidraw는 편집 원본이다. 도식은 공식 Excalidraw 0.18.1 라이브러리로 export했다. PNG는 한글·배치를 검토했으며 SVG의 글꼴은 열람 환경에 따라 다를 수 있다.

공식 화면 3장은 LiteLLM Model Management 문서가 제공한 원본이다. ZEN 화면이 아니다. 화면 버전 1.91.0/1.105.0과 조사 대상 1.92.0의 계약을 구분한다. 원본 URL·SHA256·제작 도구는 manifest.json을 참고한다. 비밀키·운영 원문은 포함하지 않았다.
