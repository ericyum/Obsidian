회의록 화면 목업 (첨부 회의록-UI목업.html — 버튼/화면 이동만 됨, 실제 녹음·전사 X)

흐름은 기존 Whisper UI를 응용: 회의록 목록이 중심. 우상단 + 새 회의록 버튼 → 새 회의록 화면(제목·참여자·옵션 + 녹음/파일 올리기) → 녹음 화면 → 완료되면 회의록 화면.

새 회의록은 모달이 아니라 화면 전환으로(기존 Whisper UI 방식). 목록 → 만들기 → 녹음 → 결과가 각각 한 화면.

회의록 화면(본체)

- 요약 / 안건별 논의 / 결정 사항 / 액션 아이템 + 밑에 공유 카드 미리보기
    
- 오른쪽에 전사 원문 패널(화자별 보기, 검색)
    
- 결정 사항 옆 근거 • 07:41 누르면 → 오른쪽 전사가 그 시간으로 넘어가 하이라이트
    
- [편집] 본문 고쳐쓰기 / [확정하고 채널에 공유] → 확정 표시
    
- 액션 아이템 체크
    

백그라운드 처리: 전사 중 → 초안 → AI 검토 → 확정 상태가 목록에 표시.

파이프라인은 기존 Whisper 작업(STT 2.5 flash, 화자 분리, AI 검토)을 그대로 얹음. 모델/추론 선택은 시스템이 자동(사용자에게 안 보임).

미정: 다크/라이트 톤, 코딩 위치(meeting-whisper vs zen-ai), 채널 게시 vs 공유 링크.
