# 회의록 에이전트 업무 개요

## 회의록 에이전트란?

**회의록 에이전트는 사용자가 채팅 스레드에서 회의 녹화를 시작·제어하고, 완성된 회의록을 확정·공유하며, 공유받은 회의록을 검색하거나 그 내용에 관해 질문할 수 있게 하는 AI 에이전트다.**

사용자는 회의 에이전트를 호출해 생성된 자신의 전용 스레드에서 필요한 업무를 요청한다.

State, Checkpoint, Tool과 같은 기술 개념과 세부 실행 구조는 [[1-2. 회의록 에이전트 워크플로우 Graph 상세]]에서 다룬다.
## 누가 사용하는가?

| 사용자 | 수행하는 업무 |
|---|---|
| **회의 생성자** | 회의 시작, 녹화 일시정지·재개·종료, 회의록 확정·공유 |
| **공유받은 사용자** | 접근 가능한 회의록 검색·선택, 선택된 회의록을 바탕으로 질문 |

> **회의 생성·진행·공유와 공유 회의록 활용은 반드시 같은 사용자의 연속 과정이 아니다.** 회의 생성자와 공유받은 사용자는 각각 회의 에이전트를 호출해 생성된 자신의 전용 스레드에서 필요한 업무를 수행한다.

## 제공 기능

회의록 에이전트는 크게 다음 기능을 제공한다.

1. 회의 시작
2. 녹화 일시정지·재개·종료
3. 회의록 확정·공유
4. 관련 회의록 검색·선택
5. 선택된 회의록을 바탕으로 질문·답변

## 한눈에 보는 전체 업무 흐름

회의록 에이전트의 업무는 크게 두 줄기로 나뉜다.

- **새 회의를 생성·진행·공유하는 흐름**
- **기존에 공유된 회의록을 검색·질문하는 흐름**

## 1. 새 회의를 생성·진행·공유하는 경우

> [!summary] 한눈에 보기
> - **사용자:** 회의 생성자
> - **시작:** 회의를 시작하지 않은 입력 대기 상태
> - **주요 행동:** 시작, 일시정지, 재개, 종료, 확정·공유
> - **결과:** 지정된 채널에 회의록 공유
> - **종료:** 다시 사용자 입력 대기

```mermaid
%%{init: {"flowchart": {"useMaxWidth": true, "nodeSpacing": 10, "rankSpacing": 14, "curve": "linear"}, "themeVariables": {"fontSize": "10px"}}}%%
flowchart LR
    I["입력 대기"] --> A["회의 시작"]
    A --> B["회의 진행"]
    B --> C["회의 종료"]
    C --> D["회의록 확정·공유"]
    D --> I
```

회의가 진행되는 동안 사용자는 녹화를 일시정지하거나 다시 재개할 수 있다. 회의가 종료된 뒤 회의록을 확정·공유하면 이 업무가 끝나고 다시 다음 요청을 기다린다.

## 2. 공유된 회의록을 활용하는 경우

> [!summary] 한눈에 보기
> - **사용자:** 회의록을 공유받은 사용자
> - **시작:** 사용자 입력 대기 상태
> - **주요 행동:** 회의록 검색·선택 또는 내용 질문
> - **결과:** 선택된 회의록 또는 회의록 기반 답변
> - **종료:** 요청 한 번을 처리한 뒤 다시 사용자 입력 대기

### 관련 회의록 검색·선택

사용자는 주제나 날짜 등의 조건으로 자신에게 접근 권한이 있는 회의록을 찾는다.

```mermaid
%%{init: {"flowchart": {"useMaxWidth": true, "nodeSpacing": 10, "rankSpacing": 14, "curve": "linear"}, "themeVariables": {"fontSize": "10px"}}}%%
flowchart LR
    I["입력 대기"] --> A["검색 조건 입력"]
    A --> B["접근 가능한<br/>회의록 검색"]
    B --> C["필요하면<br/>사용자 선택"]
    C --> D["사용할 회의록<br/>확정"]
    D --> I
```

기존에 선택한 회의록이 있다면 새 회의록을 기존 목록에 추가할지, 새 목록으로 대체할지 사용자가 선택한다.

### 회의록 질문·답변

사용자가 선택된 회의록의 내용에 대해 질문하면 에이전트는 필요한 원문을 조회해 답변한다.

```mermaid
%%{init: {"flowchart": {"useMaxWidth": true, "nodeSpacing": 10, "rankSpacing": 14, "curve": "linear"}, "themeVariables": {"fontSize": "10px"}}}%%
flowchart LR
    I["입력 대기"] --> A["회의록 내용 질문"]
    A --> B["선택된 회의록<br/>원문 조회"]
    B --> C["질문에 필요한<br/>내용 조립"]
    C --> D["AI 답변 생성"]
    D --> I
```

회의록 원문은 대화 기록에 계속 쌓지 않고 답변을 생성하는 시점에만 사용한다.

## 업무 원칙

- **사람의 선택이 필요한 부분은 사용자에게 확인한다.** 검색 후보가 여러 개이거나 기존 회의록 목록에 추가·대체해야 할 때 사용자가 직접 선택한다.
- **권한은 백엔드에서 확인한다.** AI가 사용자의 접근 권한을 임의로 판단하지 않는다.
- **회의 녹화와 과거 회의록 활용은 함께 사용할 수 있다.** 녹화 중에도 기존 회의록을 검색하거나 질문할 수 있다.
- **각 요청이 끝나도 전용 스레드는 유지된다.** 사용자는 같은 스레드에서 다음 요청을 이어갈 수 있다.
