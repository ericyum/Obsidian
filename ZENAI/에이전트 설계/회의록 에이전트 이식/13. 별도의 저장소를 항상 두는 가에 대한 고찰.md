| 저장 영역                     | 실제 위치                             | 저장 내용                                            |
| ------------------------- | --------------------------------- | ------------------------------------------------ |
| Agent State Store         | `meeting_agent_states`            | Scratchpad, 최소 HITL 참조                           |
| Workflow Checkpoint Store | `meeting_workflow_checkpoints`    | 업무 Run의 종료 경계와 상태                                |
| Tool State Repository     | 현재 회의록 상태 SQL 함수가 관리하는 Tool 전용 상태 | `authorizedMeetingIds`, 후보, 상세 HITL Snapshot, 토큰 |
| 레거시 호환                    | `agent_runs.builtin_checkpoint`   | 위 실행 결과의 호환용 JSON 표현                             |
어차피 Agent State Store에는 Snapshot이 있어서 필요하다. 그냥 아예 두 저장소를 두는 식으로 변경하는 것을 목표로 잡는다.
