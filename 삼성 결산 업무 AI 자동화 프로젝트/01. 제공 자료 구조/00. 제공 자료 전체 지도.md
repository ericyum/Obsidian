## 3. 인계물과 실행 환경은 다르다

| 제공 파일 | 실제로 갖고 있는 것 | 별도 준비·검증이 필요한 것 |
|---|---|---|
| RAP 객체·메타데이터 | 데이터 모델·상태 변경 규칙·서비스 소스 | SAP 패키지 반영·활성화·서비스 바인딩·권한·표준 API |
| Fiori ZIP·풀린 소스 | UI 소스·의존성 잠금·MTA/보안 설정·빌드 스크립트 | Node/빌드 도구·BTP 서비스·Destination·실제 OData |
| MCP ZIP·풀린 소스 | 앱·공통 Python 패키지·카탈로그·Helm·가이드 | 이미지·Secret·회사 프로필·네트워크·IAS·SAP 연결 |
| IS 내보내기 | 아티팩트 정의·OpenAPI·iFlow·Groovy·메타데이터 | Import·실제 파라미터·Security Material·배포·연결 |
| Destination 자리표시자 | 인계 설명 순서의 표시 | BTP Cockpit 실제 설정 |

**배포용 파일이 있다고 현재 배포와 동일하다는 뜻은 아니다.** 안내서에 과거 테스트 결과가 있어도 지금 이 PC·환경에서 수행한 테스트와 구별해야 한다.

### 3.1 폴더별 배포 대상과 작업 방식

**제공 폴더는 구현 자료이며, 각 구현을 반영하는 플랫폼이 다르다.** 특히 `02_RAP`는 SAP 백엔드, `05_Integration_Suite`는 IS 작업물 내보내기다.

| 폴더 | 구현과 인계 형식 | 반영·배포 대상 | 개발자가 하는 작업 |
|---|---|---|---|
| **`02_RAP`** | ABAP·CDS·테이블·Behavior·OData 객체 소스/메타데이터 | **S/4HANA ABAP 시스템** | ADT 등으로 지원 형식에 맞게 객체 반영·활성화, 서비스·권한 확인 |
| `03_Fiori_App` | UI5·AppRouter·MTA 소스와 가이드 | Cloud Foundry / HTML5 앱 구성 | 앱 빌드·서비스 연결·배포 |
| **`04_MCP_on_Kyma`** | Python MCP 앱·공통 패키지·회사 프로필·Docker/Helm | **Kyma** | 이미지·설정·Secret·네트워크·MCP 배포 |
| **`05_Integration_Suite`** | iFlow·Groovy·OpenAPI·API·MCP 아티팩트 내보내기 | **Integration Suite** | Import 후 연결·인증·파라미터 조정과 아티팩트 배포 |

`05_Integration_Suite`에는 스펙뿐 아니라 실제 iFlow·코드·매핑이 들어 있다. `02_RAP`는 그와 연결할 SAP 데이터/API 계층이며, ADT나 SAP GUI에서 MCP 서버를 배포하기 위한 파일 묶음이 아니다.

도구 차이는 [[01. RAP 백엔드 구조와 데이터 흐름#3.1 RAP의 배포 대상과 ADT 및 SAP GUI|ADT와 SAP GUI]], IS의 호출 방향과 구현 순서는 [[01. Integration Suite 실행 구조#2.1 실제 호출 방향과 JWD 연결|IS 실행 구조]]를 참고한다.

## 4. 실행 상태를 읽을 때 특히 주의할 것

| 보이는 상태/파일 | 잘못 확대하기 쉬운 해석 | 이 자료에서의 정확한 의미 |
|---|---|---|
| `AGENT_RUNNING` | SAP 작업이 확실히 시작되고 완료까지 연결됨 | RAP가 Agent 요청 상태와 시작 이력을 기록한 것 |
| RequestID 결과 조회 | 요청자의 권한·회사·모드까지 모두 검증됨 | Kyma 보조 조회는 `REQUEST_ID_ONLY` 수준 |
| HTTP/Tool 성공 | 결산이 끝났음 | 접수 또는 조회 성공일 수 있어 최종 결과 확인 필요 |
| Kyma Actions 코드 | 재무 기표 실행기가 제공됨 | 기본 비활성 설비보전 통지 초안 기능 |
| IS 계좌이체 도구 | 지급 완료 | 요청 draft 생성·활성화이며 release/pay 아님 |
| `existing-services.mtaext`라는 이름 | 기존 서비스만 안전하게 재사용함 | 실제 파일은 서비스 이름 매핑, 타입 override 없음 |
| `DIAG_FA030`라는 이름 | 읽기 전용 진단 | 실제 소스는 UPDATE/COMMIT을 포함하는 보정 도구 |
