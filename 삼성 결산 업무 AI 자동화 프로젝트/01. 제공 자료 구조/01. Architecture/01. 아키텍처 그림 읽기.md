## 위에서 아래로 읽기

| 계층 | 그림의 구성 | 의미 |
|---|---|---|
| 사용자 접점 | JWD, Fiori App | 자연어 대화와 업무 화면이 함께 존재 |
| 로그인·식별 | OAuth/SSO, IAS/Corp IdP | 기업 사용자 인증과 앱 접근 |
| BTP 실행 환경 | Kyma, Integration Suite, Cloud Foundry | 서버·연계·화면의 실행 장소/플랫폼 |
| AI 도구 | Business Insights MCP, Business Actions MCP | 조회 도구와 선택된 실행 API의 인터페이스 |
| 연결 | Destination, Cloud Connector | SAP 접속 대상·인증·네트워크 통로 |
| 업무 시스템 | S/4HANA PCE | 표준/Custom 테이블, CDS, OData 서비스 |

## 조회·실행·화면의 세 경로

| 경로 | 개념적인 순서 | 대응 인계 자료 |
|---|---|---|
| **자연어 조회** | JWD → Insights MCP → Destination/Cloud Connector → SAP OData | `04_MCP_on_Kyma` + `02_RAP` |
| **업무 실행** | JWD → IS Actions MCP → API/iFlow → SAP 실행 API | `05_Integration_Suite` + 실제 SAP 실행 서비스 |
| **업무 화면** | 브라우저 → CF AppRouter/UI5 → Destination → RAP OData | `03_Fiori_App` + `02_RAP` |

원본에는 결산·수익성·예산·자금 네 영역의 Insights 도구가 함께 있다. **다른 영역의 존재를 이번 결산 PoC 범위로 자동 포함하지 않는다.** 실제 MCP 소스에는 별도 고정자산 서비스의 planned 상태도 있으며, AFAB 결과 보조 조회와 구별한다.

## 그림과 구현 완료 여부를 구별하기

> [!important] 원본 그림의 문구는 목표 책임도 포함한다
> 그림의 “명확한 권한 및 보안 통제”, 로그인과 사용자 식별을, 현재 end-user 권한 전파가 완료됐다는 실증으로 읽지 않는다. 긴 영상 후반에서는 기술 계정 연결·전파 미완성·권한 테스트의 필요성을 설명한다.

그림은 요청의 방향을 보여 주지만, **RequestID·최종 결과·대시보드 상태 업데이트·실패 복구·사용자 권한 검증의 상세 계약은 표현하지 않는다.** 이 부분은 실제 소스와 후속 과제로 보충해야 한다.
