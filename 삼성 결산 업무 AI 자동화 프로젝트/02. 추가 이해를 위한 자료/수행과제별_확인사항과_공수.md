# PoC 수행과제별 확인사항·담당 포지션·공수

고객 미팅과 내부 담당 배정을 위한 검토 초안이다. 사용자가 제시한 **0, 1.1.1~1.1.4, 1.2.1~1.2.7의 12개 항목**을 유지했다. 상위 제목인 1.1·1.2에는 별도 공수를 붙이지 않는다.

**현재 확보한 소스·문서·영상의 분석 결과를 정리한 것이며, SAP/BTP 업무 실행을 새로 검증한 결과가 아니다.** 확인된 구현, 추가 확인, 후속 작업을 구분한다. 소스에서 발견되지 않은 기능도 외부 SAP/Joule 환경에 별도로 있을 수 있으므로, 추가 인수 여부를 확인한 뒤 개발 책임과 잔여 공수를 확정한다.

## 2. 항목별 포지션·잠정 공수

**1MD = 한 사람이 8시간 일하는 양.** 아래 숫자는 담당 역할들의 투입량 합계이며 경과일이나 필요 인원수가 아니다. 기존 [WBS 원자료](../80_산출물/03_공수산정/wbs-data.json)의 낙관/기준/비관 추정치를 중복 없이 재분류했다. 이미 작성된 코드를 처음부터 만드는 비용이 아니라, 해당 전제에서의 잔여 복원·보완·검증 비용이다. 추가 인수본이 나오면 조정한다.

**항목별 숫자는 전체 계획 안에서 해당 항목에 배정한 공수다.** 다른 항목이나 공통 행에 한 번 배정한 선행 작업이 준비되어야 완료할 수 있다. 특정 항목만 선택할 때는 그 행의 숫자만 사용하는 대신, 필요한 선행 작업을 함께 추려 재산정한다.

### 합계의 정확한 의미

| 범위 | 낙관 MD | 기준 MD | 비관 MD |
|---|---:|---:|---:|
| 산정 가능한 11개 항목 + 공통 작업 | **125** | **208.5** | **361.5** |
| 1.2.7 JWD Excel 업로드 | 추가 산정 | 추가 산정 | 추가 산정 |
| 참고: 고객이 Fiori 업로드로 대체 승인할 경우의 Excel 대안 | +9 | +14 | +23 |
| 위 Fiori 대안을 선택한 경우에만 적용하는 조건부 합계 | **134** | **222.5** | **384.5** |

- **125/208.5/361.5MD는 JWD 업로드가 빠진 잠정 산정 소계다. 전체 표의 완료 공수로 사용하지 않는다.** 산정 가능한 11개 항목을 모두 선택하고 실제 기표·취소, 전체 통합 검수·배포·인수까지 수행하는 조건이다. 단순 데모 복원이나 일부 항목만 선택하면 공통 작업도 그 범위에 맞춰 다시 산정한다. JWD 경로를 선택하면 필요한 파일 처리/저장 설계를 검토한 뒤 전체 항목을 재산정한다. Fiori 대안 14MD에 임의의 추가 숫자를 더해 JWD 공수로 만들지 않는다.
- 기준 S2 기존 236MD는 Fiori 업로드, 자동조치, 효과/비용 보고까지 포함한 다른 범위다. 이번 Fiori 대안 기준은 그중 **자동조치 E17/E18 8.5MD와 별도 보고 E19 5MD를 제외한 222.5MD**다. 두 범위의 숫자를 섞지 않는다. 낙관·비관도 같은 작업을 제외했다.
- 감가상각·외화평가 실행부를 받지 못해 신규 구현하면 B01~B03 대신 N01~N05를 적용한다. **순증 +20/+26/+39MD**이며 두 묶음을 함께 더하지 않는다. 한 종만 인수되는 혼합형은 별도 산정이다.
- Joule 설정 미인수 시 A07 대신 J01~J03 적용으로 **순증 +5/+12/+25MD**. 이는 기존 Joule host를 사용할 수 있다는 전제이며, host 자체 부재·대체 제품 구축은 포함하지 않는다.
- 사용자 전파·IS 기능 지원 불가, CBO 자체 신규 개발, 대용량/다수 포맷, 폭넓은 자율분석·자동조치는 이 범위를 벗어난다. 현재 비관 값도 이런 미정 범위의 상한을 보장하지 않는다.
- 추정은 기존 정적 분석 기반의 전문가 판단이다. 전체 추정 신뢰도는 **낮음**이며 확정 견적이 아니다. 환경·자료 제공, 숙련 담당자, 고객 정답 검수가 준비된 전제다. 신입 교육·리뷰 부담이나 미확인 추가 결함을 임의 비율로 더하지 않았다.
- 이번 문서는 기존 WBS의 항목별 재분류다. 제외 작업이 연결된 기존 의존 관계(E20/V20 등)는 범위 확정 후 재정의해야 하며 **새로운 일정 시뮬레이션을 수행한 결과가 아니다.** MD를 8명으로 나눠 완료일을 정하지 않는다.
