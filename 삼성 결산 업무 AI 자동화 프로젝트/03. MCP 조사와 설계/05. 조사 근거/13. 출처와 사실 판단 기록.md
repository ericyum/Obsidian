# 출처와 사실 판단 기록

일반 조사일 **2026-11-15** · 핵심 공개 근거 재확인·프로젝트 적용 갱신 **2026-11-17**. 공식 웹 문서·논문과 프로젝트 자료를 사용했다. 검색 결과의 관련 글 날짜를 해당 글의 발행일로 착각하지 않도록 본문 날짜를 우선했다. 예를 들어 Anthropic advanced tool use는 2026 관련 링크가 보여도 본문 발행일은 2025-11-24다.

## 1. 조사 범위와 한계

- OpenAI·Anthropic의 도구·하네스·메모리·컨텍스트·평가 관련 공식 자료를 우선 조사했다. 최신 관련 자료로 Anthropic 2026-11-06 memory, OpenAI 2026-09-10 Agents API를 포함했다. 모든 관련 논문을 망라한 체계적 문헌고찰은 아니다.
- 학술 자료는 MCP-Atlas v3, DynamicMCPBench, ComplexMCP를 보완 근거로 사용했다. 원문을 저장하거나 재배포하지 않고 핵심 시사점과 한계를 요약했다.
- SAP Help/Architecture/Community 일부는 본문 추출·접근이 제한돼 공식 검색 색인의 발췌만 사용했다. 해당 사실은 아래에 표시했다. 숫자를 현재 삼성물산 환경의 값으로 확정하지 않았다.
- MCP 2026-07-28의 규격과 2025-11-25의 구규격을 대조했다. 실제 Joule·IS의 지원 버전은 미확인이다.
- 외부 웹에 고객 문서·대화·코드·인증정보를 업로드하지 않았다. 공개 기술 질의만 검색했다.
