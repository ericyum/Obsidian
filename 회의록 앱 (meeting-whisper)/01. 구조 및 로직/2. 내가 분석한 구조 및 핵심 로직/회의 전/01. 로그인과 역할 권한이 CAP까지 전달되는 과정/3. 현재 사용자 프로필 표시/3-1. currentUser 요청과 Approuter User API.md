# 3-1. currentUser 요청과 Approuter User API

`initUserProfile()`은 `getCurrentUser()`를 호출한다.

```javascript
const user = await getCurrentUser();
```

`api.js`는 다음 요청을 보낸다.

```javascript
fetch("/user-api/currentUser", {
  credentials: "same-origin",
  cache: "no-store",
  headers: {
    accept: "application/json",
    "X-Requested-With": "XMLHttpRequest"
  }
});
```

이 요청은 CAP로 가지 않는다. `xs-app.json`의 `sap-approuter-userapi` route가 처리한다.

```text
UI
→ /user-api/currentUser
→ Approuter 내장 User API
→ 이름·이메일 등 반환
```

성공하면 반환 JSON은 프로필 표시에 사용되고 동시에 `markSessionTouched("current-user")`가 세션 활동 이벤트를 발생시킨다. 401이면 `markSessionExpired()`가 만료 이벤트를 발생시킨다.

이 응답은 화면 표시용이다. CAP의 데이터 보안 원본은 이후 `/api` 요청에 전달되는 JWT와 CAP가 만든 `req.user`다.
