# 02. 회의 시작과 브라우저 초안 생성

이 단계는 사용자가 `회의 시작` 버튼을 누른 순간부터 녹음 정보를 `currentDraft`로 묶어 브라우저에 저장할 때까지를 다룬다.

```text
start 클릭
→ 선택 파일 존재 여부 확인
→ 파일이 없을 때만 새 녹음 흐름 진입
→ 입력 옵션 읽기
→ 로그인 세션 갱신과 녹음 중 유지 타이머 준비
→ 임시 전사 상태 초기화
→ 고유 sessionId 생성
→ currentDraft 생성
→ localStorage 저장
```
