# 2-2. 세션을 확인하고 currentDraft를 저장하는 과정

## 전체 순서

```javascript
const speakerBounds = speakerBoundsFromForm();
const transcriptionOptions = transcriptionOptionsFromForm();
showEntryError("");
await startRecordingSessionKeepAlive();
// 임시 전사 상태 초기화
// sessionId 생성
currentDraft = { ... };
saveDraftMeta(currentDraft);
```

## 1. 화면 옵션을 먼저 읽는다

`speakerBoundsFromForm()`은 화자 수 범위를 검사하고, 최소값이 최대값보다 크면 오류를 발생시킨다. 현재 `transcriptionOptionsFromForm()`은 `diarize: false`를 반환하므로 화자 분리 옵션은 실질적으로 비활성화되어 있다.

오류가 발생하면 아래의 세션 유지나 녹음기 생성으로 진행하지 않고 `catch`로 이동한다.

## 2. 녹음 전에 로그인 세션을 갱신한다

```javascript
await startRecordingSessionKeepAlive();
```

`session.js`의 흐름은 다음과 같다.

```text
기존 녹음용 타이머 정리
→ refreshSession("recording-start")
→ keepAlive API 성공
→ touchSession("recording-start")
→ 30분마다 refreshSession("recording") 타이머 등록
```

`await`가 있으므로 최초 세션 확인이 실패하면 `currentDraft`와 녹음기를 만들지 않는다.

## 3. 임시 전사 메모리 상태를 비운다

```javascript
liveFinalText = "";
liveInterimText = "";
liveProcessedResultIndex = 0;
```

이전 임시 문장이 새 녹음으로 섞이지 않게 한다.

## 4. 녹음 한 건의 고유 식별자를 만든다

```javascript
const randomId = window.crypto && typeof window.crypto.randomUUID === "function"
  ? window.crypto.randomUUID()
  : String(Date.now());
```

이 값은 서버의 Meeting ID가 아니다. 브라우저 IndexedDB에 저장할 음성 조각들이 어느 녹음에 속하는지를 묶는 `sessionId`다.

## 5. 입력값을 currentDraft로 복사한다

```javascript
currentDraft = {
  sessionId: randomId,
  title: $("title").value.trim(),
  category: selectedMeetingCategory(),
  participants: [...participants],
  sharedWith: [...sharedWith],
  minSpeakers: speakerBounds.minSpeakers,
  maxSpeakers: speakerBounds.maxSpeakers,
  diarize: transcriptionOptions.diarize,
  durationSeconds: 0,
  chunkCount: 0,
  mimeType: "",
  liveText: "",
  startedAt: new Date().toISOString(),
};
```

`currentDraft`는 CAP DTO나 DB 행이 아니라 브라우저 메모리 객체다. `participants`와 `sharedWith`는 펼침 문법으로 복사하여 이후 원본 배열 변경이 초안에 저절로 섞이지 않게 한다.

## 6. 초안 메타데이터를 localStorage에 저장한다

```javascript
saveDraftMeta(currentDraft);
```

```javascript
export function saveDraftMeta(meta) {
  localStorage.setItem("meeting-whisper:draft", JSON.stringify(meta));
}
```

여기에는 제목, 참여자, 길이, 조각 수 같은 작은 설명 정보가 들어간다. 실제 음성 바이트는 크기 때문에 localStorage가 아니라 이후 IndexedDB에 저장한다.

```text
currentDraft
→ JavaScript 메모리의 현재 초안

localStorage
→ 페이지가 사라져도 남을 초안 설명서

IndexedDB
→ 다음 단계부터 저장할 실제 음성 조각
```
