# 3-2. 녹음 제어 객체와 음량 분석기를 준비하는 과정

## 음량 분석기 준비

```javascript
const ac = new AudioContext();
const src = ac.createMediaStreamSource(stream);
const analyser = ac.createAnalyser();
src.connect(analyser);
```

이 경로는 소리를 저장하는 경로가 아니라 화면의 파형을 움직이기 위한 음량 측정 경로다.

```text
마이크 stream
├─ MediaRecorder → 실제 음성 조각
└─ AudioContext analyser → 화면 파형용 숫자
```

`loop()`는 분석기의 숫자를 `onLevel(level)`로 `app.js`에 전달한다. `app.js`에서는 `updateMicLevel()`이 막대 높이를 바꾼다.

## requestAnimationFrame이 loop를 반복시키는 방식

`loop()`의 마지막에는 다음 코드가 있다.

```javascript
raf = requestAnimationFrame(loop);
```

이 코드는 브라우저가 다음 화면을 그리기 직전에 `loop()`를 다시 실행하도록 예약한다. 따라서 `loop()`는 음량을 한 번만 계산하는 함수가 아니라, 자기 자신의 다음 실행을 계속 예약하는 반복 구조다.

```text
recorder.start()
→ requestAnimationFrame(loop)로 첫 실행 예약
→ 다음 화면을 그리기 전에 loop() 실행
→ analyser에서 현재 음량 읽기
→ onLevel(level)
→ app.js의 updateMicLevel(level)
→ 화면의 음량 막대 높이 변경
→ requestAnimationFrame(loop)로 다음 실행 예약
→ 같은 과정 반복
```

`requestAnimationFrame(loop)`가 없다면 음량을 한 번만 측정하고 끝나므로 파형이 실시간으로 움직이지 않는다. `setInterval()` 대신 이 기능을 사용하면 브라우저의 실제 화면 갱신 시점에 맞춰 막대를 변경할 수 있다.

`requestAnimationFrame()`의 반환값은 다음 예약을 식별하는 번호이며 `raf`에 저장된다.

```javascript
raf = requestAnimationFrame(loop);
```

녹음을 종료하면 `closeResources()`가 이 번호를 사용해 반복을 취소한다.

```javascript
if (raf) cancelAnimationFrame(raf);
```

```text
createRecorder()
→ loop 함수와 분석기만 준비

recorder.start()
→ requestAnimationFrame 반복 시작

recorder.stop()
→ closeResources()
→ cancelAnimationFrame(raf)
→ 반복 종료
→ 마이크 track과 AudioContext도 종료
```

### 일시정지했을 때

현재 구현은 `pause()`에서 `cancelAnimationFrame()`을 호출하지 않는다. 따라서 음량 분석 `loop()` 자체는 계속 실행된다. 다만 `app.js`의 `updateMicLevel()`이 일시정지 여부를 확인하고 즉시 반환한다.

```javascript
if (!levelBars.length || !recorder || recorder.isPaused()) return;
```

```text
일시정지 중
→ loop와 onLevel(level)은 계속 실행
→ updateMicLevel(level)에 도착
→ recorder.isPaused()가 true
→ 화면 막대는 갱신하지 않음
```

## app.js에 반환하는 제어 객체

`createRecorder()`는 실제 `MediaRecorder`를 그대로 노출하지 않고 다음 기능을 가진 객체를 반환한다.

```text
mimeType  선택된 녹음 형식
start()   실제 녹음 시작
pause()   일시정지
resume()  재개
stop()    종료 후 최종 Blob 반환
requestData() 현재까지 데이터를 즉시 조각으로 요청
elapsed() 실제 녹음 시간 계산
state()   현재 내부 상태
isPaused() 일시정지 여부
```

이 객체가 전역 변수 `recorder`에 저장된다.

```javascript
recorder = await createRecorder(...);
```

따라서 이후 `app.js`는 브라우저의 원본 `MediaRecorder`를 직접 다루기보다 프로젝트가 감싼 `recorder.start()`, `recorder.pause()` 등을 사용한다.

## 초안에 실제 형식을 기록

```javascript
currentDraft.mimeType = recorder.mimeType;
saveDraftMeta(currentDraft);
```

복구 시 조각들을 어떤 형식의 Blob으로 합칠지 알 수 있게 한다.

## 실패 처리

`createRecorder()`가 실패하면 시작 버튼의 바깥 `catch`가 실행된다.

```javascript
stopRecordingSessionKeepAlive();
showEntryError(micPermissionMessage(err), 재요청가능여부);
```

이미 시작한 녹음용 세션 유지 타이머를 정리하고 사용자에게 마이크 권한 또는 장치 오류를 보여준다.
