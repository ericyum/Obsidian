# 6-2. 임시 전사의 수정 저장 재시작과 폐기 범위

## 확정 문장은 사용자가 수정할 수 있다

확정 문장 DOM에는 `contenteditable="true"`가 붙는다. `input`이나 `blur` 이벤트가 발생하면 `syncLiveFinalFromEditor()`가 화면의 문장을 다시 읽는다.

```text
사용자 문장 수정
→ syncLiveFinalFromEditor()
→ liveFinalText 갱신
→ currentDraft.liveText 갱신
→ saveDraftMeta()
→ localStorage 저장
```

## 남은 임시 문장을 확정하는 경우

`commitLiveInterim()`은 일시정지, 종료, SpeechRecognition session 종료 때 호출된다.

```javascript
if (liveInterimText.trim()) {
  appendLiveLine(liveInterimText);
  liveInterimText = "";
}
```

## 브라우저가 인식 session을 끝내도 필요하면 재시작한다

```javascript
live.onend = () => {
  commitLiveInterim();
  live = null;
  if (liveWanted && recorder && recorder.state() === "recording") {
    setTimeout(startLiveTranscript, 500);
  }
};
```

사용자가 계속 녹음 중인데 브라우저 인식 session만 종료되었다면 0.5초 뒤 새 session을 만든다.

## 최종 STT에는 전달되지 않는다

`currentDraft.liveText`는 localStorage 복구용 메타데이터에만 남는다. 녹음 종료 뒤 `createJob()`에 전달하는 인자에는 `liveText`가 없다.

```text
브라우저 임시 전사
→ liveFinalText
→ currentDraft.liveText
→ localStorage에서 끝

최종 전사
→ MediaRecorder 음성 Blob
→ CAP 저장
→ Worker Whisper STT
→ Transcripts
```

따라서 임시 전사는 최종 전사의 초안, 프롬프트 또는 교정 입력이 아니다. 화면에서 회의 중 내용을 대략 확인하는 보조 기능이다.
