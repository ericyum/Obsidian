# 08. 일시정지 중 음량 분석 RAF loop 지속 문제

> 현재 상태: **해결·`main` 반영 완료**

## 문제 현상

`MediaRecorder.pause()`로 실제 오디오 저장은 일시정지했지만 마이크 음량을 분석해 화면 막대를 움직이는 `requestAnimationFrame` loop는 계속 실행됐다.

```text
마이크 MediaStream
├─ MediaRecorder → 실제 오디오 chunk
└─ AnalyserNode → 음량 계산·화면 표시
```

두 작업은 독립적이므로 `rec.pause()`가 RAF loop까지 자동으로 취소하지 않는다.

## `raf`의 의미

```js
let raf = null;
raf = requestAnimationFrame(loop);
```

`raf`는 JavaScript의 특별한 자료형이 아니라 개발자가 `requestAnimationFrame`을 줄여 붙인 변수명이다. 변수에는 `loop()`의 실행 결과가 아니라 브라우저가 반환한 **다음 프레임 실행 예약 ID**가 들어간다.

```text
requestAnimationFrame(loop)
→ 다음 화면 프레임 전에 loop 실행 예약
→ 예약 ID 반환
→ raf에 저장

cancelAnimationFrame(raf)
→ 해당 ID의 예약 취소
```

`loop()` 안에서 다시 `requestAnimationFrame(loop)`를 호출하므로 매 프레임 새 ID가 `raf`에 저장된다.

## 초기 `pause()`의 빈틈

```text
rec.requestData()
→ rec.pause()
→ 녹음 시간 저장
→ state = paused

하지만
→ cancelAnimationFrame(raf) 없음
```

이 문제는 일시정지 구간의 음성이 저장되거나 기존 chunk가 사라지는 오류는 아니다. 실제 녹음은 멈춴지만 음량 분석·배열 합계·`onLevel()`·DOM 갱신이 불필요하게 계속되는 자원 낭비였다.

## 수정

```js
function startLevelLoop() {
  if (raf) return;
  raf = requestAnimationFrame(loop);
}

function stopLevelLoop() {
  if (!raf) return;
  cancelAnimationFrame(raf);
  raf = null;
}
```

| 상태 | MediaRecorder | 음량 loop |
|---|---|---|
| `start()` | 녹음 시작 | `startLevelLoop()` |
| `pause()` | 일시정지 | `stopLevelLoop()` |
| `resume()` | 녹음 재개 | `startLevelLoop()` |
| `stop()` | 종료 | loop·MediaStream·AudioContext 정리 |

`startLevelLoop()`의 `if (raf) return`은 중복 loop 생성을 막고, `stopLevelLoop()`의 `raf = null`은 현재 예약이 없음을 앱 내부에 표시한다.

## `timeslice`와의 차이

```text
rec.start(timeslice)
→ 오디오 chunk를 얼마나 자주 받을지

requestAnimationFrame(loop)
→ 음량 표시를 다음 화면 프레임에 갱신
```

두 간격은 서로 무관하다.

## 검증

`tests/recorder-pause-loop.test.js`는 다음을 검증한다.

- `start()` 후 RAF callback과 음량 분석 실행
- `pause()` 후 대기 RAF 0개
- 일시정지 중 analyser 읽기·`onLevel` 횟수 증가 없음
- `resume()` 후 RAF 다시 등록
- `stop()` 후 RAF 0개
