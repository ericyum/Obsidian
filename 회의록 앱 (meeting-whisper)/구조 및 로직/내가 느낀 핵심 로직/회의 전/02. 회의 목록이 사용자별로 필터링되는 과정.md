# 02. 회의 목록이 사용자별로 필터링되는 과정

이 문서는 상세 코드 워크스루의 목차다. 전체 1~8단계 분석을 완료했다.

중간 폴더 번호와 전체 단계 번호는 서로 다른 기준이다. 폴더는 주제별로 묶었기 때문에 1~6번이고, 실제 실행 흐름은 1~8단계다.

```text
loadList()
→ listMeetings()
→ readEntityList("Meetings")
→ GET /api/Meetings
→ CAP before READ Meetings
→ meetingAccessWhere(req)
→ userIdentityTokens(req.user)
→ Meetings.accessTokens와 비교
→ 허용된 Meeting 행만 반환
→ 각 Meeting의 getMeetingStatus 권한 재검사
→ Transcripts·Summaries·ReviewItems 접근 제한
→ 완성된 객체를 meetingsCache에 저장
→ 검색·필터링·렌더링
```
