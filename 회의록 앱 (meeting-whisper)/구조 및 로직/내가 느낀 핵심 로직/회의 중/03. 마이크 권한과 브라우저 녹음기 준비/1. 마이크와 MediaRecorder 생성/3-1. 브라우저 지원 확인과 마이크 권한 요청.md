# 3-1. 브라우저 지원 확인과 마이크 권한 요청

## 호출부

```javascript
recorder = await createRecorder({
  timeslice: 1000,
  onLevel: (level) => updateMicLevel(level),
  onChunk: async (blob, index) => { /* 저장 */ },
});
```

`createRecorder()`는 녹음 완료 음성을 반환하는 함수가 아니다. 녹음 시작·정지 등을 제어할 수 있는 객체를 준비해 반환한다.

## 브라우저 기능 확인

```javascript
if (!navigator.mediaDevices || !window.MediaRecorder) {
  throw new Error("이 브라우저는 녹음을 지원하지 않습니다...");
}
```

- `navigator.mediaDevices`: 마이크 같은 미디어 장치에 접근하는 브라우저 기능
- `MediaRecorder`: 마이크 스트림을 녹음 데이터로 바꾸는 브라우저 녹음기

둘 중 하나라도 없으면 여기서 중단한다.

## 마이크 권한 요청

```javascript
const stream = await navigator.mediaDevices.getUserMedia({ audio: true });
```

이 줄에서 브라우저가 사용자에게 마이크 사용 허용 여부를 묻는다. 성공하면 마이크 소리가 흐르는 `MediaStream`을 받는다.

```text
JavaScript
→ 브라우저에 오디오 장치 요청
→ 사용자가 허용
→ 운영체제 마이크의 MediaStream 반환
```

거부하면 Promise가 실패하여 `app.js`의 `catch`로 이동한다.

## 브라우저가 지원하는 음성 형식 선택

```javascript
const types = ["audio/webm;codecs=opus", "audio/webm", "audio/mp4"];
```

`pickMimeType()`은 앞에서부터 지원 여부를 확인하여 가능한 첫 형식을 고른다. MIME type은 음성 데이터가 어떤 형식으로 인코딩되었는지를 나타내는 이름이다.

## 실제 MediaRecorder 생성

```javascript
const rec = new MediaRecorder(
  stream,
  mimeType ? { mimeType } : undefined
);
```

여기까지는 녹음기를 마이크에 연결해 준비한 것이다. 실제 녹음은 이후 `rec.start(timeslice)`가 실행될 때 시작된다.
