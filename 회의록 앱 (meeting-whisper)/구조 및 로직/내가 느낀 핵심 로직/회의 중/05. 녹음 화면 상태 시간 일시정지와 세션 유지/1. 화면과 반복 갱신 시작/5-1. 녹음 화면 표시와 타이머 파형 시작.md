# 5-1. 녹음 화면 표시와 타이머 파형 시작

## 시작 직전 코드 순서

```javascript
show("view-recording");
paintLiveTranscript();
$("rec-title").textContent = currentDraft.title || "회의";
$("rec-chips").innerHTML = 참여자칩;
$("timer").textContent = "00:00";
$("pause-resume").textContent = "일시정지";
setRecordingStatus(false);
recorder.start();
startLiveTranscript();
timerInt = setInterval(updateRecordingTimer, 500);
initMicGraph();
```

## 화면 표시와 녹음 시작은 별개다

`show("view-recording")`는 `index.html`의 녹음 영역을 보여줄 뿐이다. 실제 마이크 녹음은 뒤의 `recorder.start()`가 시작한다.

```text
show("view-recording")
= 화면 전환

recorder.start()
= MediaRecorder 실제 녹음 시작
```

화면에는 초안 제목과 현재 참여자 배열을 표시하고 타이머와 버튼 문구를 초기 상태로 맞춘다.

## 0.5초 타이머

```javascript
timerInt = setInterval(updateRecordingTimer, 500);
```

`updateRecordingTimer()`는 0.5초마다 실행되지만 표시 시간은 `recorder.elapsed()`가 계산한 초 단위 값이다.

```javascript
const elapsed = recorder.elapsed();
$("timer").textContent = fmtClock(elapsed);
currentDraft.durationSeconds = elapsed;
currentDraft.liveText = liveFinalText;
saveDraftMeta(currentDraft);
```

따라서 타이머는 화면 숫자만 바꾸는 것이 아니라 초안의 녹음 길이와 임시 전사도 localStorage에 반복 저장한다.

## 음량 파형

`initMicGraph()`가 28개의 막대를 만들고, `recorder.js`의 AudioContext 분석기가 전달하는 `level`을 `updateMicLevel()`이 막대 높이와 투명도로 바꾼다.

```text
마이크 stream
→ analyser
→ onLevel(level)
→ updateMicLevel(level)
→ wave 막대 CSS 변경
```

파형은 녹음 데이터 그 자체가 아니라 현재 마이크 소리 크기를 시각적으로 보여주는 UI다.
