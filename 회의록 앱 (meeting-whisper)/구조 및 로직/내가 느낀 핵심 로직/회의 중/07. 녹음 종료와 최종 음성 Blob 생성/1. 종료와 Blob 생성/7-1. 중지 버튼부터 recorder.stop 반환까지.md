# 7-1. 중지 버튼부터 recorder.stop 반환까지

## app.js가 먼저 멈추는 것

```javascript
const duration = recorder.elapsed();
clearInterval(timerInt);
commitLiveInterim();
stopLiveTranscript();
stopRecordingSessionKeepAlive();
const blob = await recorder.stop();
```

```text
최종 실제 녹음 시간 확보
→ 화면 타이머 중지
→ 남은 임시 전사 확정
→ 브라우저 SpeechRecognition 중지
→ 녹음용 로그인 세션 유지 타이머 중지
→ 실제 MediaRecorder 중지 요청
```

## recorder.stop 내부

```javascript
if (typeof rec.requestData === "function" && rec.state !== "inactive") {
  rec.requestData();
}
rec.stop();
```

종료 직전 아직 방출되지 않은 데이터를 마지막 조각으로 요청한 뒤 MediaRecorder를 중지한다.

`onstop` callback에서는 다음을 수행한다.

```javascript
state = "inactive";
closeResources();
resolve(new Blob(chunks, { type: mimeType || "audio/webm" }));
```

`closeResources()`는 파형 애니메이션을 중지하고 마이크 track과 AudioContext를 닫는다.

## 반환되는 Blob

```text
메모리 chunks의 모든 조각
→ new Blob(chunks)
→ 하나의 연속된 음성 데이터 객체
→ await recorder.stop()의 반환값
```

`Blob`은 아직 파일 경로나 서버 주소가 아니다. 브라우저 메모리 안에 있는 최종 음성 바이트 묶음이다.
