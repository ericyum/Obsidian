## 개발 용어를 몰라도 읽는 방법

- 파일명은 “근거가 있는 위치”를 알려 줄 때만 적었다.
- 파일 내용을 한 줄씩 설명하지 않는다.
- 처음 나오는 개발 용어는 바로 뒤에서 쉬운 말로 풀이한다.
- 세부 코드보다 책임, 데이터 이동, 실패 시 행동을 중심으로 설명한다.

## 이 문서에서 자주 사용하는 표현

| 표현 | 뜻 |
|---|---|
| 프론트엔드 | 사용자가 보는 화면 |
| 백엔드 | 화면 뒤에서 데이터와 업무 규칙을 처리하는 부분 |
| API | 화면과 백엔드가 서로 요청하고 답하는 약속된 통로 |
| 데이터베이스 | 회의 정보와 결과를 오래 보관하는 저장소 |
| Worker | 시간이 오래 걸리는 전사 작업만 맡는 별도 프로그램 |
| 배포 | 만든 프로그램을 실제 사용 가능한 서버 환경에 올리는 일 |
| 인증 | “누가 접속했는가”를 확인하는 과정 |
| 권한 | 확인된 사용자가 “무엇을 할 수 있는가”를 결정하는 규칙 |
