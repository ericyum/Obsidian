## 구현 대상에서 제외한 항목

- 일반 `UPDATE`·`DELETE` 차단: 내부 사용 환경에서 악의적 우회 요청만을 주로 가정하므로 제외한다.
- 참여자·공유자 중복 방지: 두 역할이 겹쳐도 참여자 권한으로 필요한 작업을 할 수 있어 치명적 사용 장애가 아니다.
- 자동 저장 revision·서버 낙관적 잠금: 가능성은 있지만 현재 정상 사용에서 발생하는 치명적 오류로 확인되지 않아 보류한다.
- AI 작업 실행 ID 전체 개편: 오래된 결과 덮어쓰기 시나리오가 실제 UI 흐름에서 재현되기 전에는 구현하지 않는다.
- 요약·검토 작업 고착 복구: 팀 동료 담당이므로 이 폴더의 작업 대상과 문서에서 제외한다.
- [[06. 회의 생성 업로드 enqueue 중간 실패와 중복 회의 문제]]: 현상은 재현했지만 현재는 적용하지 않는다. 배포 환경에서는 Object Store 음원이 전사·요약 완료 후 정리되고, 기존 제작자의 업로드·enqueue 흐름을 바꾸는 회귀 위험이 더 크다고 판단했다. 실험 수정은 revert했다.
