# 01. 로그인과 역할 권한이 CAP까지 전달되는 과정

이 문서는 전체 호출 순서를 보는 목차다. 자세한 코드는 같은 이름의 폴더 안에서 위에서 아래로 읽는다.

```text
앱 URL 접속
→ Approuter와 XSUAA 인증
→ 정적 UI 전달
→ app.js 초기화
→ 브라우저 세션 감시
→ 현재 사용자 프로필 표시
→ /api 요청과 JWT 전달
→ CAP의 req.user와 MeetingUser 검사
→ 로그인 직후 회의 목록 화면으로 연결
```
