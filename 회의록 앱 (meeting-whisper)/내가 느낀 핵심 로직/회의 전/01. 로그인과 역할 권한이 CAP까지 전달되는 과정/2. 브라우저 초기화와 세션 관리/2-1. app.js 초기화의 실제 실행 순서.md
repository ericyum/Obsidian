# 2-1. app.js 초기화의 실제 실행 순서

`app/meeting-ui/js/app.js` 마지막 부분은 다음 순서로 실행된다.

```javascript
initSessionMonitor({ keepAlive: keepSessionAlive });
initUserProfile();
const initialRoute = routeFromLocation();
writeRoute(initialRoute, { replace: true });
applyRoute(initialRoute).catch((error) => {
  loadList({ replaceHistory: true });
});
```

```text
세션 감시 장치 설치
→ 현재 사용자 조회
→ 현재 URL 해석
→ 목록 또는 상세 화면 선택
```

`initSessionMonitor()`는 최초 로그인을 하지 않는다. 로그인 후 브라우저 측 세션 활동과 만료 UI를 관리한다. `initUserProfile()`은 현재 사용자가 누구인지 조회해 화면에 표시한다.

두 함수의 실행 순서도 의미가 있다.

```text
먼저 session-touch·session-expired 이벤트 수신 준비
→ 그다음 currentUser 요청
→ 요청 성공·실패 이벤트를 놓치지 않고 처리
```

`routeFromLocation()`은 URL의 `meeting` Query Parameter가 있으면 상세 화면을, 없으면 목록 화면을 선택한다.
