# 3-2. DOM helper와 사용자 메뉴 표시

`ui.js`의 `$`는 특별 문법이 아니라 짧게 만든 함수다.

```javascript
export const $ = (id) => document.getElementById(id);
```

따라서 `$("user-menu")`는 `id="user-menu"`인 DOM 요소를 찾는다. `user-menu`는 태그명이 아니라 `div`의 ID다.

```html
<div class="user-menu hidden" id="user-menu">
  <span id="user-avatar"></span>
  <span id="user-name"></span>
  <strong id="user-popover-name"></strong>
  <span id="user-popover-email"></span>
</div>
```

`$()` 자체는 값을 넣지 않는다. 실제 값 입력은 `.textContent`가 담당한다.

```javascript
$("user-name").textContent = displayName;
$("user-popover-email").textContent = email;
```

```text
$()
= 요소 검색

.textContent = 값
= 찾은 요소에 글자 입력

classList.remove("hidden")
= 사용자 메뉴 표시
```

브라우저 화면의 사용자명을 개발자 도구로 바꿔도 CAP 권한은 바뀌지 않는다. 이 DOM은 표시용이고 서버 보안은 JWT와 `req.user`를 기준으로 한다.
