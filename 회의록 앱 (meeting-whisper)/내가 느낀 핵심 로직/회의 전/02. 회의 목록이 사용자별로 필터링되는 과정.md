# 02. 회의 목록이 사용자별로 필터링되는 과정

이 문서는 상세 코드 워크스루의 목차다. 현재 4단계까지 분석을 완료했다.

```text
loadList()
→ listMeetings()
→ readEntityList("Meetings")
→ GET /api/Meetings
→ CAP before READ Meetings
→ meetingAccessWhere(req)
→ userIdentityTokens(req.user)
→ 다음 단계: Meetings.accessTokens 생성과 저장
```
