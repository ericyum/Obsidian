# 1-1. loadList에서 listMeetings까지

기본 URL에서 `applyRoute()`는 목록 화면을 선택하고 `loadList()`를 호출한다.

```text
app.js 초기화
→ routeFromLocation()
→ applyRoute({ view: "list" })
→ loadList()
```

`loadList()`는 목록 화면 표시, URL 필터 복원과 로딩 Skeleton 표시 후 다음 코드를 실행한다.

```javascript
meetingsCache = await listMeetings();
updatePeopleSuggestions();
renderMeetingCategoryFilter();
renderMeetingListView();
```

`listMeetings()`는 `useCapApi()`를 호출한다. 그 안의 `apiMode()`가 현재 URL을 검사하며, 원격 배포 도메인이나 로컬 CAP 포트 4004·5000에서는 `"cap"`을 반환한다.

CAP 모드에서는 다음 분기를 실행한다.

```javascript
const meetings = await readEntityList("Meetings", {
  orderby: "createdAt desc"
});
```

브라우저의 화면 검색 조건으로 사용자 권한을 결정하지 않는다. 이 시점에는 CAP에 `Meetings` 목록을 요청할 준비만 한다.
