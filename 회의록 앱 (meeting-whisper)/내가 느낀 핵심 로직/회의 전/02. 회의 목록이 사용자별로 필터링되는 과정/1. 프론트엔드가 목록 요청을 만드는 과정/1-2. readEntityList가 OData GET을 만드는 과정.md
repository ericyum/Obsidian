# 1-2. readEntityList가 OData GET을 만드는 과정

호출 인자는 다음과 같다.

```text
entity = "Meetings"
filter = 없음
orderby = "createdAt desc"
```

`readEntityList()`는 OData Query Parameter를 만들고 공통 `requestJson()`을 호출한다.

```javascript
async function readEntityList(entity, { filter, orderby } = {}) {
  const params = new URLSearchParams();
  if (filter) params.set("$filter", filter);
  if (orderby) params.set("$orderby", orderby);
  const query = params.toString().replace(/\+/g, "%20");
  const suffix = query ? `?${query}` : "";
  const data = await requestJson(`/api/${entity}${suffix}`);
  return data.value || [];
}
```

실제 요청은 대략 다음 형태다.

```text
GET /api/Meetings?$orderby=createdAt desc
```

여기에는 `owner = 현재 사용자` 같은 권한 조건이 없다. 브라우저는 `Meetings`를 최신순으로 요청하고, 사용자 접근 조건은 CAP가 서버에서 추가한다.

```text
requestJson()
→ fetch()
→ Approuter /api route
→ forwardAuthToken으로 JWT 전달
→ CAP MeetingService
```
