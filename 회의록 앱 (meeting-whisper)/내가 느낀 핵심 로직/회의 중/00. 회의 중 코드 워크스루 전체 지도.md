# 00. 회의 중 코드 워크스루 전체 지도

## 이 묶음이 다루는 범위

이 묶음은 사용자가 새 회의 화면을 열고 실제 녹음을 시작한 뒤, 녹음을 끝내 하나의 최종 음성 `Blob`을 얻을 때까지를 다룬다.

```text
새 회의 화면 열기
→ 회의 정보 입력
→ 회의 시작
→ 브라우저 초안 생성
→ 마이크와 녹음기 준비
→ 음성 조각 생성과 보관
→ 녹음 화면·시간·일시정지 관리
→ 즉석 임시 전사 표시
→ 녹음 종료
→ 최종 음성 Blob 생성
```

CAP에 `Meetings` 행을 만들고 음성을 업로드하는 `createJob()`부터는 녹음이 끝난 뒤의 서버 처리이므로 `회의 후` 문서에서 이어서 본다.

## 회의 후와의 경계

다음 호출부터는 회의 중이 아니라 회의 후 처리로 본다.

```javascript
currentJob = await createJob(blob, ...);
```

```text
여기까지 회의 중
최종 음성 Blob 확보
==============================
여기부터 회의 후
CAP Meetings 생성
→ 음성 업로드
→ 전사 작업표 생성
→ Worker 전달
```
