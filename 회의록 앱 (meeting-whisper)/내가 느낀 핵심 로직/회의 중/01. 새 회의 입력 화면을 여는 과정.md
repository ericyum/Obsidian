# 01. 새 회의 입력 화면을 여는 과정

이 문서는 회의 목록을 보고 있던 사용자가 `+ 새 회의록` 버튼을 눌러 새 회의 입력 화면을 얻는 과정을 다루는 목차다.

```text
index.html의 new-meeting 버튼
→ app.js가 등록한 onclick 실행
→ 이전 회의 입력 상태 초기화
→ show("view-entry")
→ index.html의 새 회의 입력 영역만 표시
→ 사용자가 입력한 값은 DOM과 JavaScript 배열에 머무름
```

이 단계에서는 아직 다음 일이 일어나지 않는다.

```text
마이크 권한 요청 안 함
녹음 시작 안 함
currentDraft 생성 안 함
CAP Meetings 행 생성 안 함
서버 네트워크 요청 안 함
```
