# 1-2. 새 회의를 위해 브라우저 상태와 입력값을 초기화하는 과정

## 왜 먼저 초기화하는가

사용자가 이전에 새 회의를 작성하다가 목록으로 돌아왔거나 업로드에 실패했다면 JavaScript 변수와 입력창에 이전 값이 남아 있을 수 있다. `new-meeting` 클릭 함수는 새 입력 화면을 보여주기 전에 이러한 값을 초기 상태로 되돌린다.

## 실제 코드

```javascript
$("new-meeting").onclick = () => {
  uploadInFlight = false;
  pendingUpload = null;
  participants = [];
  sharedWith = [];
  renderChips();
  renderShareChips();
  updatePeopleSuggestions();
  autoGeneratedTitle = "";
  titleWasManuallyEdited = false;
  $("title").value = "";
  renderEntryCategoryOptions();
  $("meeting-category").value = "";
  $("meeting-category-custom").value = "";
  syncCategoryInput({ updateTitle: false });
  $("audio-file").value = "";
  if ($("whisper-model")) $("whisper-model").value = "";
  if ($("diarize-mode")) $("diarize-mode").checked = false;
  if ($("min-speakers")) $("min-speakers").value = "";
  if ($("max-speakers")) $("max-speakers").value = "";
  syncDiarizeFields();
  syncFileUploadCta();
  showEntryError("");
  show("view-entry");
};
```

## 초기화 대상을 큰 덩어리로 보기

### 1. 이전 업로드 상태

```javascript
uploadInFlight = false;
pendingUpload = null;
```

- `uploadInFlight`: 지금 파일이나 녹음을 서버에 올리는 중인지 표시한다.
- `pendingUpload`: 업로드 실패 후 재시도할 데이터를 보관한다.

새 회의를 시작할 때는 이전 업로드 작업의 상태를 끊어낸다.

### 2. 참여자와 공유자

```javascript
participants = [];
sharedWith = [];
renderChips();
renderShareChips();
updatePeopleSuggestions();
```

배열을 비운 뒤 화면의 칩을 다시 그린다. `renderChips()`와 `renderShareChips()`는 빈 배열을 기준으로 기존 칩을 제거한다.

`updatePeopleSuggestions()`는 Picker가 열려 있는 특수한 상황이라면 후보 메뉴도 최신 배열에 맞춰 다시 그리는 방어 코드다.

### 3. 제목과 카테고리

```javascript
autoGeneratedTitle = "";
titleWasManuallyEdited = false;
$("title").value = "";
renderEntryCategoryOptions();
$("meeting-category").value = "";
$("meeting-category-custom").value = "";
syncCategoryInput({ updateTitle: false });
```

기존 회의 제목과 카테고리를 지운다. `renderEntryCategoryOptions()`는 `meetingsCache`에서 알고 있는 카테고리들을 선택지로 다시 만든다.

`syncCategoryInput({ updateTitle: false })`는 현재 카테고리 선택 상태에 맞춰 직접 입력 칸의 표시 여부를 정리하되, 초기화 도중 새 자동 제목을 만들지는 않도록 한다.

### 4. 파일과 전사 옵션

```javascript
$("audio-file").value = "";
if ($("whisper-model")) $("whisper-model").value = "";
if ($("diarize-mode")) $("diarize-mode").checked = false;
if ($("min-speakers")) $("min-speakers").value = "";
if ($("max-speakers")) $("max-speakers").value = "";
syncDiarizeFields();
syncFileUploadCta();
```

이전에 선택한 음성 파일과 화자 관련 입력값을 지운다. 파일이 사라졌으므로 `syncFileUploadCta()`는 시작 버튼을 다시 일반적인 `회의 시작` 상태로 맞춘다.

### 5. 오류와 화면

```javascript
showEntryError("");
show("view-entry");
```

이전 오류 메시지를 숨긴 뒤 새 회의 입력 영역을 표시한다.

## 초기화 전후

```text
초기화 전
participants = ["김철수"]
sharedWith = ["이영희"]
pendingUpload = 이전 실패 데이터
title = "지난 회의"
audio-file = 이전 파일

초기화 후
participants = []
sharedWith = []
pendingUpload = null
title = ""
audio-file = 없음
view-entry만 표시
```

## 중요한 경계

이 초기화는 브라우저 화면과 JavaScript 변수에만 적용된다. DB에 저장된 기존 회의를 삭제하거나 수정하는 것이 아니다.
