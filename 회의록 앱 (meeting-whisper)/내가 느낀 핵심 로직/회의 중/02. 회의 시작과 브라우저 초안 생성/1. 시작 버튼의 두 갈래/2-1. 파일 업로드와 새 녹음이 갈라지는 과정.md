# 2-1. 파일 업로드와 새 녹음이 갈라지는 과정

## 시작점

`index.html`에는 `#start` 버튼이 하나뿐이지만 선택된 파일 여부에 따라 역할이 달라진다.

```javascript
$("start").onclick = async () => {
  if (selectedAudioFile()) {
    await uploadSelectedFile();
    return;
  }

  try {
    // 새 녹음 준비
  }
};
```

`selectedAudioFile()`은 파일 입력 요소의 첫 파일을 반환한다.

```javascript
function selectedAudioFile() {
  return $("audio-file")?.files?.[0] || null;
}
```

## 두 갈래

```text
#audio-file에 파일 있음
→ selectedAudioFile()가 File 반환
→ uploadSelectedFile()
→ return
→ 아래의 마이크 녹음 코드 실행 안 함

#audio-file에 파일 없음
→ selectedAudioFile()가 null 반환
→ if 통과
→ try 안의 새 녹음 준비 실행
```

따라서 기존 파일 업로드는 녹음 중 흐름에 포함되지 않는다. 마이크 권한, `currentDraft`, `MediaRecorder`, 실시간 임시 전사를 모두 건너뛴다.

## 버튼 글자도 같은 기준으로 바뀐다

```javascript
function syncFileUploadCta() {
  if (uploadInFlight) return;
  const file = selectedAudioFile();
  setStartButtonLabel(file ? START_FILE_LABEL : START_RECORDING_LABEL);
}
```

파일 선택 상태가 실제 분기 조건이고 버튼 글자는 그 상태를 사용자에게 보여주는 표현이다.

```text
파일 없음: 회의 시작
파일 있음: 파일 전사 시작
```
