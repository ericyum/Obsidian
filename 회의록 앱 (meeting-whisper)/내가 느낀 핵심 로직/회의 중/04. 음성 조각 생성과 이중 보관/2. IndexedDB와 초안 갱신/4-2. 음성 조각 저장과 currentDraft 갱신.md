# 4-2. 음성 조각 저장과 currentDraft 갱신

## onChunk callback의 역할

`recorder.js`가 조각을 넘기면 `app.js`의 callback이 현재 초안 설명을 갱신하고 실제 조각을 IndexedDB에 저장한다.

```javascript
onChunk: async (blob, index) => {
  const draft = currentDraft;
  if (!draft) return;

  const next = {
    ...draft,
    mimeType: recorder?.mimeType || blob.type || "audio/webm",
    durationSeconds: recorder?.elapsed() || draft.durationSeconds,
    chunkCount: Math.max(draft.chunkCount || 0, index + 1),
    lastChunkAt: new Date().toISOString(),
  };

  await saveDraftChunk(draft.sessionId, index, blob);
  currentDraft = next;
  saveDraftMeta(currentDraft);
}
```

## IndexedDB에 저장되는 실제 행

```javascript
store.put({
  key: `${sessionId}:${index}`,
  sessionId,
  index,
  blob
});
```

예를 들면 다음과 같다.

```text
abc-session:0 → 첫 번째 Blob
abc-session:1 → 두 번째 Blob
abc-session:2 → 세 번째 Blob
```

`sessionId`는 녹음 한 건을 구분하고 `index`는 그 안의 순서를 구분한다.

## 저장 성공 후 메타데이터 갱신

IndexedDB 저장이 성공한 뒤에만 다음 값들이 `currentDraft`와 localStorage에 확정된다.

```text
mimeType       음성 형식
durationSeconds 현재 녹음 길이
chunkCount     현재까지 저장된 조각 수
lastChunkAt    마지막 저장 시각
```

## 녹음이 바뀐 경우를 막는 확인

```javascript
if (!currentDraft || currentDraft.sessionId !== draft.sessionId) return;
```

비동기 IndexedDB 저장을 기다리는 동안 사용자가 다른 상태로 넘어갔다면 오래된 callback이 새 `currentDraft`를 덮어쓰지 않도록 한다.

## 저장 실패

```javascript
currentDraft = {
  ...currentDraft,
  draftError: err?.message || "녹음 조각 저장 실패",
};
saveDraftMeta(currentDraft);
```

녹음 메모리 자체를 즉시 중단하지는 않지만 복구용 IndexedDB 저장에 문제가 생겼다는 사실을 메타데이터에 남긴다.

## 왜 이중 보관하는가

```text
메모리 chunks
→ 정상 종료 시 최종 Blob을 빠르게 생성
→ 페이지가 종료되면 사라짐

IndexedDB chunks
→ 페이지 종료 후에도 복구 가능
→ 정상 업로드 성공 후 deleteDraft()로 정리
```
