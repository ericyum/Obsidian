# 5-2. 일시정지 재개 실제 녹음 시간과 세션 유지

## 버튼 이벤트

```javascript
$("pause-resume").onclick = () => {
  if (!recorder) return;
  if (recorder.isPaused()) {
    recorder.resume();
    // 버튼과 상태를 녹음 중으로
    startLiveTranscript();
  } else {
    recorder.pause();
    // 버튼과 상태를 일시정지로
    commitLiveInterim();
    stopLiveTranscript();
  }
  updateRecordingTimer();
};
```

하나의 버튼이 현재 `recorder.isPaused()` 값에 따라 pause와 resume을 번갈아 수행한다.

## pause 내부

```javascript
if (typeof rec.requestData === "function") rec.requestData();
rec.pause();
activeMs += Date.now() - segmentStartMs;
state = "paused";
```

일시정지 전에 현재까지의 데이터를 조각으로 요청하고, 방금까지 실제 녹음한 구간 시간을 `activeMs`에 누적한다.

## resume 내부

```javascript
rec.resume();
segmentStartMs = Date.now();
state = "recording";
```

새 녹음 구간의 시작 시각을 기록한다.

## 실제 녹음 시간 계산

```javascript
elapsed() {
  const running = state === "recording"
    ? Date.now() - segmentStartMs
    : 0;
  return Math.floor((activeMs + running) / 1000);
}
```

```text
activeMs
= 이미 끝난 녹음 구간들의 합

running
= 지금 진행 중인 녹음 구간

일시정지 시간
= 계산에 포함되지 않음
```

## 임시 전사와 함께 멈추고 재개한다

일시정지하면 화면에 남은 임시 문장을 확정하고 SpeechRecognition을 중지한다. 재개하면 다시 시작한다. 브라우저 녹음과 임시 전사가 서로 다른 기능이지만 사용자가 느끼는 상태를 맞춘 것이다.

## 녹음 중 로그인 세션 유지

2단계에서 `startRecordingSessionKeepAlive()`가 최초 세션을 갱신하고 30분 간격 타이머를 등록했다.

```javascript
recordingTimer = setInterval(() => {
  refreshSession("recording");
}, RECORDING_KEEPALIVE_MS);
```

이 타이머는 일시정지 때는 멈추지 않는다. 회의 녹음 작업 전체가 끝날 때 `stopRecordingSessionKeepAlive()`로 정리된다.
