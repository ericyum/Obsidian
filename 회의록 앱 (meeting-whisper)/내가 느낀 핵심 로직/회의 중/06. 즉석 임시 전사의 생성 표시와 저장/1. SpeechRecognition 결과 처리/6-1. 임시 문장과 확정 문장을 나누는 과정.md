# 6-1. 임시 문장과 확정 문장을 나누는 과정

## 시작

```javascript
const SpeechRecognition = window.SpeechRecognition || window.webkitSpeechRecognition;
live = new SpeechRecognition();
live.lang = "ko-KR";
live.continuous = true;
live.interimResults = true;
live.start();
```

지원하지 않는 브라우저에서는 녹음은 계속할 수 있지만 임시 전사 화면에 지원되지 않는다고 표시한다.

## 두 종류의 결과

SpeechRecognition은 아직 바뀔 수 있는 결과와 확정된 결과를 함께 준다.

```text
isFinal = false
→ liveInterimText
→ 화면에 임시 문장으로 표시

isFinal = true
→ appendLiveLine(text)
→ liveFinalText에 줄 단위로 누적
```

`liveProcessedResultIndex`는 이미 확정 처리한 결과를 다음 이벤트에서 다시 추가하지 않도록 기억한다.

## onresult 흐름

```text
onresult(event)
→ 사용자가 화면에서 수정한 확정 문장 먼저 회수
→ 새 final 결과를 liveFinalText에 추가
→ 아직 final이 아닌 결과를 liveInterimText로 합침
→ paintLiveTranscript()
```

`paintLiveTranscript()`는 확정 문장과 임시 문장을 서로 다른 DOM으로 표시한다. 확정 문장은 수정 가능하고 임시 문장은 별도 줄로 보인다.
