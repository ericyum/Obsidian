# 8-1. localStorage와 IndexedDB를 확인해 복구 배너를 만드는 과정

## 앱 목록 화면에서 초안을 확인한다

`paintDraftBanner()`는 먼저 `getDraftMeta()`로 localStorage의 `meeting-whisper:draft` 값을 읽는다.

```text
메타 없음 또는 sessionId 없음
→ 배너 숨김

메타 있음
→ sessionId로 IndexedDB 조각 조회
```

## 메타데이터만 믿지 않고 실제 조각 수를 확인한다

```javascript
chunkCount = (await loadDraftChunks(meta.sessionId)).length;
```

localStorage의 `chunkCount`가 남아 있어도 IndexedDB 저장이 실패했을 수 있다. 그래서 실제 저장된 조각을 다시 읽어 업로드·저장이 가능한지 결정한다.

## 복구 배너

조각이 있으면 제목, 녹음 길이, 조각 수와 다음 버튼을 표시한다.

```text
업로드
저장
다른 이름으로 저장
삭제
```

조각이 없으면 복구 기록은 표시하지만 업로드와 저장 버튼을 비활성화한다. `draftError`나 조각 읽기 오류도 함께 보여준다.

## 페이지 종료 직전 마지막 조각 요청

녹음 중 `beforeunload`와 `pagehide`가 발생하면 다음을 시도한다.

```javascript
recorder.requestData?.();
updateRecordingTimer();
```

브라우저가 닫히기 전에 남은 음성 조각과 최신 시간을 최대한 남기려는 안전장치다. 종료 환경에 따라 모든 비동기 저장 완료를 보장하는 장치는 아니므로 복구 배너가 실제 IndexedDB 조각 수를 재검사한다.
