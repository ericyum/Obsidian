# 8-2. 조각을 합쳐 저장 업로드 또는 삭제하는 과정

## 조각 읽기

```javascript
const rows = req.result
  .filter((row) => row.sessionId === sessionId)
  .sort((a, b) => a.index - b.index);

resolve(rows.map((row) => row.blob));
```

`loadDraftChunks()`는 같은 `sessionId`의 행만 고르고 `index` 순서로 정렬하여 Blob 배열을 반환한다.

## 하나의 음성으로 복원

```javascript
const type = meta.mimeType || "audio/webm";
const blob = new Blob(chunks, { type });
```

정렬된 조각을 하나의 최종 음성 Blob으로 합친다.

## 저장 또는 다른 이름으로 저장

`downloadRecoveredDraft()`는 복원한 Blob을 일반 다운로드하거나 사용자가 선택한 위치에 저장한다. 서버 요청은 하지 않는다.

## 업로드

`uploadRecoveredDraft()`는 복원 Blob과 localStorage 메타데이터의 제목·참여자·공유자·길이 등을 `createJob()`으로 넘긴다.

```text
IndexedDB 조각
→ Blob 복원
→ 세션 확인
→ createJob()
→ 회의 후 서버 처리
```

성공하면 `deleteDraft(meta.sessionId)`로 복구 데이터를 지운다. 실패하면 `pendingUpload`에 복원 Blob과 메타데이터를 남겨 다시 업로드할 수 있게 한다.

## 삭제

사용자가 확인 대화상자에서 삭제를 확정하면 `deleteDraft(sessionId)`가 실행된다.

```text
localStorage의 초안 메타 제거
→ IndexedDB에서 sessionId 접두사를 가진 모든 조각 삭제
→ 복구 배너 다시 그림
```

삭제 후에는 되돌릴 수 없으므로 확인 대화상자를 거친다.

## 최종 요약

```text
정상 종료 경로
메모리 chunks → 최종 Blob

중단 복구 경로
IndexedDB chunks → 최종 Blob

두 경로 모두 이후에는 같은 createJob() 서버 흐름으로 합류
```
