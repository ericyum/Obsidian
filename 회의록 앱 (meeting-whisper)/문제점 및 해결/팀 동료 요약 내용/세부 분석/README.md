## 읽을 때 지켜야 할 기준

- `현재 코드에서 확인`은 실제 소스에 존재하는 동작이다.
- `운영 문서에서 확인`은 저장소의 Runbook이나 배포 문서에 적힌 절차다.
- `제안 또는 주의`는 아직 구현됐다는 뜻이 아니다.
- 모델 지원 여부와 종료일은 코드만 보고 확정할 수 없다. SAP AI Core의 Model Discovery 결과와 SAP Note를 다시 확인해야 한다.
