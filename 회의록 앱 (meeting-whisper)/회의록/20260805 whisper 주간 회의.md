# 회의록

## 요약

금주 회의에서는 STT 모델의 긴 무음 구간 처리, 웹/대용량 파일 업로드 오류 등 다양한 기술적 문제 해결 현황을 공유하고 운영 환경 검증을 논의했습니다. Gemini 2.5, 3.1, 3.5 전사 모델 성능을 비교 분석했으며, 엑세스 토큰 구조 개선 및 기능 배포 전략에 합의했습니다. 회의 일시 정지 시 리소스 낭비 개선 및 서버 종료 시 요약/검토 기능 복구 로직 안정화 작업이 진행 중입니다.

## 결정 사항

- 웹 브라우저에서 녹음된 .webm 파일 업로드 시 발생하는 오류는 파일 헤더를 분석하여 동적으로 파일 형식을 인식하도록 처리한다.
- 1MB 이상 오디오 파일 업로드 시 익명 사용자 요청의 바디를 강제로 읽도록 처리하여 인증 오류를 해결한다.
- 참여자 및 공유자 권한 중복 문제는 현재 기능적 문제가 없으므로 개선 우선순위를 낮게 유지한다.
- 화자 분리 기능은 과거 성능 문제로 인해 현재는 재도입하지 않으며, 향후 성능 개선 가능성을 재검토한다.

## 액션 아이템

- STT 및 파일 업로드 관련 오류를 운영 환경에서도 해결
- 확장자 문제 해결을 위해 헤더단 설정을 통한 업로드 가능 여부를 테스트
-  엑세스 토큰 생성 로직을 불규칙한 긴 문자(UID) 기반으로 변경하는 방안 검토 및 계획 수립
- 회의 중 일시 정지 시 불필요하게 동작하는 리소스 낭비 개선 방안을 조사하고 구현 (기한: 금요일까지)
- 회의의 전반적인 아키텍처 흐름(특히 일시 정지 시 청크 처리 등)을 문서화
- 로컬 상에서의 로그아웃 관련 문제
- 요약/검토 기능 서버 종료 시 복구 로직

## 안건별 요점

### STT 모델 및 파일 업로드 오류 현황
- 현황: STT 모델의 긴 무음 구간 처리, 웹 브라우저 .webm 파일, 1MB 이상 오디오 파일 업로드 관련 오류가 로컬에서 확인 및 일부 해결됨.
- 이슈: 일부 STT 모델(2.5, 3.5, 3.1)에서 긴 무음 구간 처리 시 오류가 발생함.
- 다음: 로컬에서 해결된 오류들을 운영 환경에서 검증할 예정임.

### 백엔드/UI 안정화 및 최적화
- 현황: 로컬 바디 파이프 오류, UI 전사 패널 크래시, 로그아웃 캐시 문제, 회의 목록 조회 시 과다 요청 문제 등이 해결됨.
- 이슈: 회의 중 일시 정지 시 UI 파형 표시 관련 메소드의 불필요한 백그라운드 실행으로 리소스 낭비가 발생함.
- 다음: 디스플레이 스피커에 방어 로직 추가 및 일시 정지 시 리소스 낭비 개선 방안을 조사하고 구현할 예정임.

### 전사 모델 성능 비교
- 현황: 2.5, 3.1, 3.5 모델의 전사 품질 비교가 진행 중이며, 모델별 강약점이 파악됨.
- 이슈: 날짜 인식 오류, 3.1 모델의 환각 생성, 3.5 모델의 잡담 분류 실패가 확인됨.
- 다음: 2.5와 3.5 모델 추가 테스트 및 3.6 모델 출시 시 즉시 테스트 예정.

### 엑세스 토큰 구조 개선
- 현황: 현재 엑세스 토큰은 이메일, 이름 조합으로 저장되어 보안 및 충돌 위험성이 있음.
- 다음: UID 기반의 불규칙한 문자열로 엑세스 토큰을 생성하는 로직으로 변경하는 방안을 검토할 계획임.

### 요약/검토 기능 서버 종료 시 복구 로직
- 현황: 요약/검토 기능 진행 중 서버(CP)가 종료되면 진행 상태가 멈추고 자동 복구되지 않는 문제가 있었음.
- 해결: DB에 임계값을 설정하여 1분 이상 상태 변동 없을 시 자동으로 이전 상태로 복구되도록 코드가 추가됨.
- 다음: 실제 동작 및 안정성을 추가로 확인해야 함.
